- **VectorIter[T] for resource-type T trips Ptr-ABI codegen panic in for-loops**: `for x in v.iter():` on `Vector[String]` panics in `c_lir/emit_types.rs:1645` ("Ptr ABI received scalar value '__v61' (type Some(I64)). Scalars should use Scalar, not Ptr."). Minimal repro: any iteration sugar (`v.iter()`, `set_iter[String](s)`, `dict_iter_keys[String, V](d)`) that materializes a `VectorIter[T]` where T is String. `VectorIter[int]` works fine with the same shape, so the breakage is in how resource-type element storage flows through the VectorIter struct when the for-loop dispatches `.next()`. Users iterate by index (`for i in 0..v.len():`) or via builtin HOFs (`v.each(...)`) until the ABI tag mismatch is fixed. Set iterator sugar ships for scalar T only; Dict key iteration likewise.
