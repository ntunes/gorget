=== PART D (unified check_safety_stmts) — DESIGN ===
SafetyState struct: { Dict[String,int] moved; int loop_depth; Dict[String,int] loop_locals; String rebind }
  - moved = the flow-sensitive branched state (cloned per branch, unioned moved-in-any).
  - loop_depth/loop_locals/rebind = structural loop context (saved/restored around loop+assign arms,
    NOT part of branch clone). scope_id STAYS an ambient int param (constant per fn body, doesn't branch
    — bundling it would just clone a constant). Extensible: new axes add a field.
Merge is MECHANICAL arm-for-arm (the two walks already mirror the same Stmt/Expr enums):
  each arm runs the stateless carrier-ops rejects AND the stateful liveness update in ONE traversal.
  Branch arms (SIf/SMatch/EIf/EMatch): clone moved per branch, run carrier+liveness in that single
  body walk, union (live_branch/live_commit wrap it). Loop arms: depth++, fresh loop_locals, one body
  walk doing both + MoveInLoop, restore, merge. Call arms ECall/EMethodCall EXACT ORDER:
    (1) callee liveness (+ConsumeCallable consume) & carrier-ops-on-callee,
    (2) per-arg loop: liveness move/use (mark left-to-right) + carrier-ops ctor/ingest reject,
    (3) check_call_aliasing (skip-move-first).  => liveness precedes aliasing (rider satisfied).
  NON-mechanical arms: NONE — the two walks agree on traversal everywhere; the only per-arm constraint
  is call-arg-liveness BEFORE check_call_aliasing.
