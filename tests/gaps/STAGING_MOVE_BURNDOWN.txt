# The class fires when an `Assign` into an owned slot is sound ONLY because the
# staging site emitted its own `MoveZero` on the source — `[Mv] _dst = copy
# _src; move_zero _src` with a real later read of `_src`. `Liveness::compute`
# counts `MoveZero` as a kill, so the defect vouches for itself and the
# always-fatal consume-site validator passes it; the class re-asks the question
# against a `MoveZeroPolicy::Blind` liveness. See `src/ir/validate.rs`.
#
# The class has NO env-gate runway on the validator (a new consume class is
# fatal the instant it lands), so it enters through the non-fatal
# `assign_warnings` list and `GG_STAGING_MOVE_GUARD=fatal` promotes it. THIS
# FILE is what makes that promotion observable: `scripts/staging_move_burndown.sh
# --check` runs it in CI and this ledger is the expected outcome.
#

#   TRIP  <fixture> <n_violations>   must STILL violate under the promoter.
