# LEAK ALLOWLIST — sanitize sweep (LeakSanitizer)
#
# Resource debt, not soundness. Tolerable in bulk WHILE IT BURNS DOWN; the
# corruption list next door is the one that must stay near zero.
#
# Measured 2026-08-18 by the first corpus-wide sweep: 316 of 1697 fixtures that
# build-and-run leak (18.6%, ~540KB total). That number is not luck — every
# fixture is gated on stdout, and a leak is stdout-invisible while a
# use-after-free usually is not, so the corpus selects FOR leaks and AGAINST
# corruption. This list is the backlog that selection created.
#
# ⚠ SHRINK-ONLY, enforced by `sanitize_allowlists_shrink_only` in tests/lints.rs.
# Removing a name is the normal outcome of a fix. ADDING one means a new leak
# shipped — fix it instead.

# citations"*. It covers four rows admitted at R47 close, and ONLY those. They

# `f3feea79`, each is absent from THAT commit's 316-row allowlist, and the
# 92-line sweep script of that commit classified each `LEAK` and reported it —
# so this gate was RED at round-open and the 2026-08-18 baseline had simply
# UNDERCOUNTED. Admitting them records debt that already existed; it tolerates
# nothing new. The exception is spelled PER ROW, not here: every one of the four
# carries its own `⚖ ADMITTED` block naming the filed item that owns the defect,
# the mechanism, and what retires the row. A fifth row without such a block is

# between the two readers of the same field. A third TAB column is already
# tolerated by every consumer: tests/lints.rs asserts `cols.len() >= 2`, the
# sweep's malformed check is `NF < 2`, the adjudicator reads `$1`/`$2` only, and
# `CORRUPTION_ALLOWLIST.txt` has been 3-column with a justification assert since
# it was written.

# exists to catch — so it fails the lint, which names the number to move. A
# widening is an admission; make it deliberately or not at all.
#
# The second column is what the fixture is tolerated FOR, and it is checked.
# A bare stem — which is all this file used to carry — tolerated ANY leak in
# that fixture forever: a second, entirely unrelated mechanism appearing inside
# an already-listed fixture was invisible to the gate. MANY rows carry two or
# more distinct mechanisms, every one of which used to hide behind a single

#   grep -v '^#' tests/sanitize/LEAK_ALLOWLIST.txt | grep -c ','
