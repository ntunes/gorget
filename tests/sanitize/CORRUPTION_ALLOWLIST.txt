# MEMORY-CORRUPTION ALLOWLIST — sanitize sweep (ASan)
#
# Use-after-free, double free, buffer overflow, stack-use-after-scope. These are
# SOUNDNESS holes: memory safety is the language's entire claim, so this list is
# meant to be SHORT, every row individually filed and justified, and to SHRINK
# every round. It is deliberately separate from the leak list — one merged list
# would let a use-after-free hide behind three hundred leaks, which is exactly
# how a `Set[String]` double free sat filed as a MED *leak* for three weeks.
#
# Format: <fixture-stem> <TAB> <sanitizer-kind> <TAB> <why it is here>
# A row with no justification is a bug in this file.
#
# ⚠ SHRINK-ONLY. Adding a row means shipping a known memory-corruption bug —
# it needs an owner decision and a filed TODO entry, not a quiet append.


stack_guard_deep_recursion	ASAN_stack-overflow	INTENTIONAL, not a defect: the fixture's whole purpose is to prove the stack guard fires on unbounded recursion. ASan reports the overflow it is designed to cause. This row is permanent unless the fixture is retired.
