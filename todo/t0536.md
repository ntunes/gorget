- **⭐🆕 [MED — D39 PHASE C of 3: the `.nth(i)` / `.key_at(i)` ordinal accessors.]** Small and additive, and the phase that actually delivers the capability D38 withholds from `[]`. Two sub-questions still OPEN and to be decided in this phase, not before: the exact name (`.nth(i)` is clean for a set; on a map it must first answer *"returns what?"* — `key_at`/`value_at`/`entry_at`), and whether `HashSet`/`HashMap` get one at all (recommendation: **no** — they stay open-addressed, so it would be O(n) returning an arbitrary element; escape hatch is `.items()`, documented unordered). Also updates `E_NotIndexable`'s message to name the accessors concretely (see the filed diagnostic-ergonomics entry). Prereq: Phase A.
