- **Self-host: extend `tc_types.expr_types` write-through to more Expr arms; consider span-keyed-sidecar replacement.** Rust writes `expr_types: FxHashMap<Span, TypeId>` at 10 sites (`typecheck.rs` 1619/1712/1756/1762/1770/1778/2026/2049/4481/4502); self-host covers the architectural-analogue subset (EAwait/ESpawn/parse written; 41+ infer_expr_type-family conversion + Rust 1770's inlined-builtin-chain deferred). Two follow-ons:
  1. **Extend write-through coverage** as the lowerer grows query sites (builtin-method chain, closure-return inference, EAs cast, EBlock body-ret). Add per query site, never speculatively (full-coverage cost ~100s on self-host's own source).
  2. **Span-keyed sidecar smell.** Both use a `Dict[Span, TypeId]` sidecar (byte offsets, span-collision-prone; today protected by per-module offset shifting in `loader.gg`). Cleaner = a typed field on `SpannedExpr` (`int resolved_type`). Pioneering this diverges from Rust — only worth it if Rust agrees to follow or a span-collision bug surfaces. Pair-port to Rust if/when redesigned.
