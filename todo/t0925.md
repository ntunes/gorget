- **🆕🚨 [HIGH — THE ROUND-CLOSE SWEEP CAN PASS HAVING RUN ZERO TESTS, AND EXIT 0; observed 2026-08-31 by the R48 Track-D2 executor, orchestrator-verified at `scripts/run_integration.sh:66`]**
  - **THE LINE.** `exec cargo test --test integration "$@" -- --test-threads="$N"`. Everything the caller passes is interpolated **before** cargo's `--`, so cargo reads it as *its own* arguments, not the harness's. A caller writing what looks obviously right — `scripts/run_integration.sh --skip self_host` — hands `--skip self_host` to **cargo**, which treats the words as a filter, matches nothing, and reports **`0 passed; 2748 filtered out`** with **exit 0**.
  - **⚠ WHY IT IS DANGEROUS RATHER THAN MERELY AWKWARD.** The failure is a **green zero**. `AGENTS.md`'s Round-lifecycle step 4 makes this wrapper the round-close C sweep, and a sweep that runs nothing looks exactly like a sweep that passes: same exit code, no red, and the count is buried in output nobody re-reads once the last line says `ok`. **It is the round-close battery's own verifier failing silently** (Core #13 — a gate that has never been seen to fail is not evidence; this one cannot fail).
  - **⭐ THE TELL IS ALREADY PRINTED — nothing reads it.** cargo's own summary line carries `N passed; M filtered out`. The guard is one assertion: **a sweep that filtered out everything, or executed zero tests, must FAIL, not pass.**
  - **CANDIDATE FIXES, none evaluated.** (a) move `"$@"` **after** the `--`, which is where a harness argument belongs, and pass any cargo-level filter through an explicit env var or a named flag the wrapper parses; (b) keep the position but **assert a non-zero executed count** before exiting 0 — cheapest, and it catches every future mis-invocation rather than the one spelling; (c) both. ⚠ (a) alone silently changes the meaning of every existing caller that currently passes a cargo filter and gets away with it — **census the callers first**.
  - **INTENDED:** a mis-invocation of the round-close sweep is LOUD. A run that executes zero tests exits non-zero and says so.
