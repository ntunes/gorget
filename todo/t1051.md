- **[MED — THE REFERENCE LAGS THE SELF-HOST ON COST (not on soundness); measured 2026-09-03 by R49 Track K while porting the `t0871` view tag] Rust gg clones at EVERY String-view bind; the self-host clones only when the source can actually change.**
  - **MEASURED**, `gg build --clones=stats tests/fixtures/string_slice_cost_colon_bind.gg`: 100 iterations of `String t = s[0:5]` where `s` is **never mutated** → Rust `string_clone=100`. The self-host's `decide_svardecl_emission` gives **0** for the same program: its Branch A aliases a view while `cow_pristine_after(bound_name)` **and** `cow_pristine_after(source_root)` both hold at the bind position, and materializes otherwise. Same stdout, same soundness, 100 clones apart.
  - **WHERE.** Rust's Branch D (`source_live && !Borrowed && is_resource_type`) and Branch E (`View && same_type_string`) in `lower_var_decl_assign_mode` (`src/ir/lowering/stmts/mod.rs`) both call `emit_clone_to_owned` unconditionally — no position-aware pristine test. The self-host's equivalent test already exists and is used by two other branches in the same function.
  - **THIS IS D52's ACCEPTED COST, NOT A DEFECT** — *"soundness first, at the accepted cost of safe-but-wasteful cloning"* — so it is filed as work, not as a bug. But the CoW charter says implicit clones must be **as good as the best hand-written code**, and a hand-written slice of a string nobody touches costs nothing. The self-host demonstrates the shape; port it back the way `t0871` ported the tag forward.
  - **⚠ THE GUARD MOVES WITH IT.** `slice_spelling_cost_equivalence` (`tests/integration.rs`) pins `string_clone == LOOP_N` at a bind for BOTH spellings. When this lands, both spellings drop to 0 together and that row becomes `== 0` — edit the row, never one spelling. Its docstring says so.
  - **Prerequisite check:** Rust has no `cow_pristine_after` equivalent keyed on (name, position); `cow_before_mutation`'s call-site set is the nearest machinery. Own scout — measure the bootstrap's `string_clone` and peak RSS before and after, since the self-host sources are slice-heavy.
