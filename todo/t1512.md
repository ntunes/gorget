- **🆕🐛 [MED — A CHECK-PHASE ACCEPT FOR A SHAPE THE LOWERING CANNOT BUILD. Found incidentally 2026-09-06 by R51 Track F's brief-review pass 3, while writing equip probes.]**

  An `equip` method declared **without `self`** passes `gg check` with `OK: no semantic errors`. The program then fails at the **C compiler** with an arity error naming generated symbols the user never wrote.

  ⛔ **THIS IS THE CORE #10 SHAPE FROM THE CHECK SIDE.** *Lower-or-reject* says every construct is either lowered or gets a **check-time rejection**; here the check phase accepts and the failure is deferred to `cc`, so the diagnostic points at emitted C rather than at the declaration. A user cannot act on it.

  ⚠ **Found while a probe was being MISDIAGNOSED as a compiler gap.** The reviewer's malformed `equip` probes (missing the `[K,V]` prefix and explicit `&self`) initially read as a lowering defect; the controls failed identically, which is what identified the real shape. **The reject-gap is what made a user error look like a compiler bug** — that is the cost of a missing rejection, independent of the miscompile it was mistaken for.

  **INTENDED:** `gg check` rejects an `equip` method with no `self` receiver, naming the declaration and the missing receiver. Ships with a `known_gaps` repro asserting the intended rejection.
