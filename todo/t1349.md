  ```gorget
  MapIter[Self, T, U, F] map[U, F](self, F f):   return MapIter[Self, T, U, F](self, f)   # lib/std/iter.gg:290
  FilterIter[Self, T, F] filter[F](self, F p):   return FilterIter[Self, T, F](self, p)   # lib/std/iter.gg:293
  ```

  **`f` / `p` are generic `F`**, so `pack_closure_at_dest_type`'s destination predicate — `GirType::FnPtr` or `c_runtime_alias == "GorgetClosure"` — **never fires**, and the struct-field init stores an **alias of a borrowed parameter**. Per the CoW contract a field init is an **ownership boundary and must clone**. So the env has **two handles and exactly one drop** (the adapter's).
