- **🆕 [MED — A DEADLOCK CLASS THAT HAS NOW FIRED THREE TIMES IN ONE ROUND AND IS POLICED BY PROSE ONLY. Core #6: prose rots, guards don't.]** Agents write a wait as

  ```sh
  until ! pgrep -f "scripts/some_sweep.sh"; do sleep 60; done
  ```

  `pgrep -f` matches **every** concurrent agent's run of that script — and, worse, **each watchdog's own command line contains the literal pattern**, so two such waiters match each other and neither ever exits. R50 observed two wrappers alive for **4h21m** spinning on patterns that no live process satisfied, plus one earlier occurrence in a committed script.

  **`AGENTS.md` multi-agent rule 9 already states the rule** (*"scope every wait predicate to the agent's OWN run: a PID file, or its own `OUT=` path"*). It is being violated anyway, which is the definition of a rule that needs an executable guard.

  **THE GUARD.** A `tests/lints.rs` ratchet over committed scripts and agent-facing docs: flag `pgrep -f` / `pkill -f` whose pattern is a bare script or binary name with no run-scoping token (`$$`, a PID file, a `/tmp/<agent-id>` path). Env-gate → burn down → fatal, both directions (Core #6).

  ⊕ **The same shared-namespace hazard has a `/tmp` twin** — two agents on one track picking the same mnemonic prefix — and a filename ratchet would not catch it. Name that omission rather than pretending the lint closes the whole class.

  ---
  ## ⛔ SHARPENED 2026-09-05 — **THE PREDICATE IS SELF-MATCHING, AND THE RULE DOES NOT YET NAME THAT FORM**

  `AGENTS.md` and this item both describe the hazard as **cross-agent**: one agent's `pgrep -f "<shared script>"` matches *another* agent's run. **Measured by R50 Track A2's executor, the live form is worse and simpler:**

  ⛔⛔ **`pgrep -f` MATCHES THE WAITER'S OWN COMMAND LINE.** The wrapper `until ! pgrep -f "robustness_map.py …"; do sleep …; done` contains that pattern **as its own argv**, so the predicate **can never go false** — with or without any sibling agent. **Two agents have been stuck on it for 9+ hours in this round alone**, and the same shape was observed for 4h21m earlier the same day.

  ⇒ ⭐ **THE LINT MUST CATCH THE SELF-MATCH, NOT ONLY THE SHARED NAME.** A wait whose pattern is scoped to a PID file or the agent's own `OUT=` path is safe; a wait whose pattern appears **in its own command line** is a deadlock **by construction**, independent of concurrency. The cross-agent framing understates it and would let a single-agent occurrence through.

  ⊕ **`pgrep -f` has flags for exactly this** (excluding the caller), which is why the fix is a lint rather than a wrapper: the failure is that people write the naive form, not that a safe form does not exist.
