- **[MED — Core #2 name-matching inside the census tool, and it makes `--fast` a lie] `scripts/known_gaps_census.sh`'s `is_sh_row` decides "does this row drive the self-host lowerer?" by GREPPING THE TEST BODY FOR THREE HELPER NAMES** — `assert_self_host_stdout`, `self_host_emit_cc_run`, `build_gg_dir_cached`. Any roster row that reaches the driver through a helper NOT on that list is invisible to it, so `--fast` runs it anyway and still pays the ~90 s `driver.gg` build. That is the layering chapter's rule 2 violated at a tool boundary — a semantic fact ("this row is expensive") inferred from an identifier string — which is the same defect class R47 F1 was opened to retire in `runtime_parity_excluded`, one directory over.
  - **REPRODUCE** (no count is quoted here on purpose — the roster changes whenever anyone files a gap, which is exactly why the script's cost figures had to be replaced with commands): for each row of `scripts/known_gaps_census.sh --list`, take its `fn` body out of `tests/integration.rs`, ask whether it transitively reaches `build_gg_dir_cached`, and compare against what `is_sh_row` matches. The delta is the blind set.
  - **CONCRETE MEMBERS, measured at HEAD `f0519417`** via the helpers `assert_self_host_rejects` / `self_host_accepts_and_emits` / `assert_self_host_rejects_comprehension`, none of which `is_sh_row` names: `known_gap_sh_len_on_float_silently_miscompiles`, `known_gap_sh_reject_misses_computed_receiver`, `known_gap_sh_string_method_on_vector_overaccepted`, `sh_rejects_unknown_scheduler_mode`. ⚠ **That is a LOWER BOUND from one enumeration of helper names** — itself a name-based method, and therefore the wrong instrument to trust for a total. An independent review of the same defect counted ten. **The number is not the finding; the detector is.**
  - **Consequence, and it is why this is worth fixing rather than noting:** the script's own header advertised `--fast` at 14 s, a figure that was never reachable while the blind set was non-empty, and that figure survived in FIVE places. Anyone reaching for `--fast` to make the CI step cheap gets nearly the full cost and a `SKIPPED_SH` count that under-reports what it skipped. The stale timings are now replaced by the regeneration command everywhere; this item is the mechanism behind one of them.
  - **Fix = ask the harness, not the source text.** The reference-grade shape is a TYPED declaration the row carries and the script reads through one accessor — e.g. the `#[serial(self_host_lowerer_driver)]` attribute, which is already the honest marker for exactly this property (every driver-sharing test must carry it, and the serial key IS the driver), or an explicit marker attribute enumerated in one place. Either replaces a three-name grep with a fact the row states about itself. ⚠ Whatever is chosen must be able to catch ITS own class (Core #15e Q2): a new driver-sharing test that forgets the marker should be visible, so pair the change with an assertion that the marker set and the transitive-reach set AGREE — that pairing is the guard, not the detector.
