- **🆕🧹 [LOW — typed-metadata debt, filed 2026-09-03 by R49 Track E as its own reference-grade follow-up; the one-line note it ships is the DELIBERATE narrow choice, this is the general shape] A TYPED RETIRED-KEYWORD TABLE, consulted where `suggestion` is computed, replacing the per-keyword string branch in the `UndefinedName` Display arm.**
  **THE STATE TODAY, and why it is a class and not an instance.** Removing the implicit-`it` closure parameter turned every `xs.map(it * 2)` in the wild into `E_UndefinedName`, where the generic path computes an edit-distance suggestion and answers *"did you mean `xs`?"* — `it`/`xs` is distance 2, so the compiler is confidently wrong and points at the receiver of the very call the user was writing. R49 Track E displaced that with a note (`src/semantic/errors.rs`, the `UndefinedName` arm), keyed on `name == "it"`. That is ONE branch for ONE keyword.
  **THERE IS ALREADY A SECOND MEMBER, retired with no note at all.** `src/lexer/token.rs` carries `// "mod" removed as keyword — now .mod() method on ints` — a comment where the keyword's entry used to be, and nothing else: a program spelling `x mod y` gets whatever edit distance finds. Two members, two different treatments, and the next retirement inherits neither.
  **THE REFERENCE-GRADE SHAPE (Layering rules 2 and 4).** A typed table of retired spellings — the retired name, what replaced it, and the sentence to print — consulted where the suggestion is DECIDED (`src/semantic/resolve.rs`, at the `scopes.suggest_name(name)` call) rather than where the error is FORMATTED, and surfaced as a typed `Option` field on `SemanticErrorKind::UndefinedName` beside `suggestion`. The decision then lives at the writer, one source of truth per axis, and the Display arm just renders what it was handed. Retiring the NEXT keyword becomes a row, not a branch.
  ⚠ **This is NOT the "no name matching" rule.** That rule governs SEMANTIC decisions in the pipeline; a retired-keyword table is diagnostic text keyed on a spelling, which is exactly what it must be keyed on. The debt is that the table does not exist, not that a string is compared.
  **SIZE.** An order of magnitude larger than the note it replaces — it threads a new typed field through the error kind and its construction sites — which is why R49 Track E shipped the note and filed this rather than growing that track's scope. `it_removed_error/main.gg` asserts the note TEXT, so it pins the behaviour either way and does not need rewriting when the table lands.
