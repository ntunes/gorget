- **🆕🐛 [MED — SELF-HOST DIAGNOSTIC QUALITY, a LOSSLESSNESS gap at the parser→AST boundary (Layering rule 1). Filed by R48 Track β, which hit it landing `t0825`'s directive validation and could not fix it inside its file zone.] The self-host AST gives no `Item` variant a span, so every ITEM-GRANULARITY diagnostic renders its caret at line 1, column 1 — pointing at whatever happens to be the file's first line.**
  - **MEASURED at HEAD** (`tests/fixtures/self_host_lowerer/driver tests/fixtures/unknown_scheduler_mode_error.gg lib --lir-c`): the message is right and the location is fiction —
    ```
    error[E_UnknownDirective]: unknown directive `scheduler=bogus`
      ┌─ tests/fixtures/unknown_scheduler_mode_error.gg:1:1
    1 │ # Test: `directive scheduler=<mode>` REJECTS an unknown mode …
      │ ^
    ```
    The directive is on line 25; line 1 is a comment. Rust gg points at the directive (`Directive.span`, `src/parser/mod.rs::parse_directive` merges start..end). Same verdict, so no lane divergence — a QUALITY gap on the lane the succession plan makes the reference.
  - **MECHANISM.** Rust gg's module is `Vec<Spanned<Item>>`; the self-host's is `Vector[Item]` (`tests/fixtures/self_host_typechecker/ast.gg`, `struct Module: Vector[Item] items`), and no `Item` variant carries a span of its own — `IDirective(String, String)` is the sharpest example, since both payloads are plain strings. So `validate_directives` (`self_host_typechecker/resolve.gg`, twinned in `self_host_resolver/resolve.gg`) has literally nothing to pass to `Diagnostic.error` and passes `Span(0, 0)`. This is Layering rule 1 (lossless on invariants): the parser HAS the span at `parse_directive_item` and drops it.
  - **FIX SHAPE — the narrow one, 12 sites.** Give `IDirective` a third payload field: `IDirective(String, String, Span)`. Sites: three `ast.gg` variant declarations (parser / resolver / typechecker); three `parse_directive_item` construction sites; three `format.gg` arms (`case IDirective(name, value)` → add `_`); two `resolve.gg` `validate_directives` arms (which then pass the real span); and **`tests/fixtures/self_host_lowerer/lower.gg:3774`'s `case IDirective(dir_name, dir_value):`**. ⚠ That last one is why R48 β did not do it: `lower.gg` belonged to a PARALLEL TRACK's file zone that round, and an arity change there is a guaranteed merge collision. It is a one-line change with no other coupling.
  - **FIX SHAPE — the general one.** Every other item-granularity diagnostic has the same hole waiting: the honest fix is a `SpannedItem` wrapper (or a span field per variant) mirroring `Spanned<Item>`, at which point `Module` becomes `Vector[SpannedItem]` and the whole class closes. Bigger, and it touches every `match item:` in the self-host — its own track.
