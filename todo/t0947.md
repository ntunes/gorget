- **🆕🐛 [HIGH — Core #10 SILENT DROP of user STATEMENTS, `gg check` clean, both backends; live in shipped stdlib; found 2026-09-02 by R48 Track R's J1 characterization] `auto x = <METHOD call returning Result>` binds the Ok PAYLOAD by auto-propagation, and the user's whole `if x.is_error():` block is then silently DISCARDED.**
  Measured on a pure-Gorget program with no externs (`gg build --emit-gir`): the local is `_4: bool ; j` — the Ok payload — and the Error basic block is the compiler's *synthesized* propagation (`enum_init Error { copy <payload> }`). Neither `print("handled")` nor `return Error("custom message")` from the user's block appears in the GIR or in the emitted C. `gg check` reports "OK: no semantic errors".
  **WHAT DISCRIMINATES IT from the auto-propagation family already filed** (`t0050` value-plane auto-prop kill, `t0101` indirect-call skip, `t0105` free-vs-method argument asymmetry, `t0434` consumer-side nets): all of those are about a `Result` flowing into a `T` *value position*. This one is a VAR-DECL binding, and its damage is that user STATEMENTS vanish — not that a call is skipped or an argument mistyped. Its discriminators, each measured on the same program shape:
  | shape | behaviour |
  |---|---|
  | `auto j = s.join(g)` (METHOD call) | auto-propagates; the `if j.is_error():` block is DISCARDED |
  | `auto j = free_fn(g)` (FREE call) | binds the `Result`; the block RUNS |
  | `Result[bool, String] j = s.join(g)` (explicit) | binds the `Result`; the block RUNS |
  So only `auto` + a method call reaches the discarding path.
  **LIVE IN SHIPPED STDLIB.** `lib/xtd/p2p.gg`'s `p2p_enable_discovery` had exactly this shape (`auto join = node.disc_socket.join_multicast(...)` + `if join.is_error(): return Error(join.unwrap_error().clone())`). R48 Track R rewrote that site to the explicit `Result[bool, String]` binding so the source says what it does; the compiler defect is untouched and lives here.
