- **🆕⚖ [LOW — ergonomic consistency, NOT a correctness bug; re-triaged 2026-08-03, supersedes the "Track D reject may be wrong" flag] Direct `.enumerate()` works on Vector but not on Set/HashSet.** Track D's reject is **sound and NOT an ordering question** (the flag filed on 2026-08-02 was wrong about its basis): `Set`/`HashSet` impl `Iterable[T]`, not `Iterator[T]`, and `.enumerate()` is an Iterator adapter — the same reasoning would apply if Set were unordered. The remaining wrinkle is only that `Vector` gets direct `.enumerate()` sugar while Set must spell `.iter().enumerate()`. Defensible on the typing, and the fix-it makes it discoverable — **once the fix-it compiles** (see the panic entry above; fix that FIRST, this is cosmetic by comparison). Decide then whether to add the Set sugar or document the asymmetry.
