- **🆕📐 [LOW — A LATENT EQUALITY HAZARD R51 Track H WIDENED THE POPULATION OF WITHOUT INTRODUCING. Named 2026-09-06 by that track's second brief-review; re-verified at source by its executor.]**

  ```rust
  pub fn insert(&mut self, ty: GirType) -> TypeId {
      let id = TypeId(self.types.len() as u32);
      self.types.push(ty);
      id
  }
  ```
  (`src/ir/types.rs:449-453` — regenerate: `grep -n 'pub fn insert' -A 4 src/ir/types.rs`.) **No interning, no lookup, no dedupe.** Two mappings of the same `Ref[T]` parameter therefore hand back two different `TypeId`s naming one `GirType`.

  ⛔ **STATED AT ITS OWN SCOPE: Track H WIDENS THE POPULATION, IT DOES NOT INTRODUCE THE HAZARD.** The registry has always behaved this way and every other repeatedly-registered type already has it. What changed is that declared `Ref[T]`/`MutRef[T]` parameters used to collapse onto the SHARED `UNIT_TYPE` sentinel — accidentally dedupe-safe, for the same reason they were miscompiled — and now mint a fresh `Ptr(T)` per site.

  **WHY NOTHING IS RED TODAY.** The one new consumer, `callee_param_is_declared_ptr` in `src/ir/lowering/exprs/calls.rs`, compares **structurally** (`matches!(registry.get(t), Some(GirType::Ptr(_) | GirType::MutPtr(_)))`), never by id. Measured over 5419 fixtures: `gg check` verdict and message identical on every one, 0 differences; emitted C differs on 23, all 23 build+run byte-identical on C and on LLVM.

  ⚠ **THE RISK IS THE NEXT CONSUMER.** A future caller-vs-callee parameter check written as `caller_tid == callee_tid` will now see a mismatch that `UNIT_TYPE` used to hide — and it will look like a real type disagreement. That is the shape of `todo/t1505`'s own defect read backwards, so it is worth pinning before someone writes it.

  **INTENDED:** either intern structural types in `TypeRegistry::insert` (a `HashMap<GirType, TypeId>` side table — note the Layering "one source of truth per axis" rule applies to the table itself), or a `debug_assert`/lint at the comparison sites that parameter types are compared structurally. Prefer interning: it removes the hazard rather than documenting it.
