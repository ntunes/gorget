- **🆕🐛 [HIGH — A LEAK *AND* AN O(n)-PER-CALL COST HIDING BEHIND A CORRECT ANSWER. Measured 2026-09-06 by R51 Track K's scout while pricing an unrelated migration.]**

  `Dict.drain()` tombstones **a throwaway clone**, not the source. ⇒ **the source is never tombstoned**, and each call re-clones the entire map.

  ⭐ **WHY IT SURVIVED: THE ANSWER IS RIGHT.** Draining twice yields the correct result *because the clone is fresh each time* — the defect is invisible to any stdout assertion, which is why no fixture caught it. **SIX-Q #6 at the level of a whole method: the cell is green for a reason unrelated to what it tests.**

  **Measured:** `Dict[String,String]` drain leaks **12982 bytes in 93 allocations** under ASan; the discarded clone is never freed.

  **INTENDED:** `drain` tombstones the source in place and returns its contents; no clone, no leak, and a second drain is genuinely empty rather than accidentally-correct.

  ⚠ **Regenerate before acting:** build the binary and read `--clones=stats` **off the built binary, never through `cargo test`** (which swallows `gg`'s stderr — `[[t0028]]`), and confirm the ASan figure with a positive control in the same invocation.
