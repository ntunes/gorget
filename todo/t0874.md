  - **THE MECHANISM.** `tests/lints.rs:20788` (`fuzz_targets_still_compile`) runs `cargo check --locked --manifest-path fuzz/Cargo.toml` with **`.env("CARGO_TARGET_DIR", "/tmp/gg_fuzz_lint_target")` — a FIXED absolute path.** Every agent worktree on the box shares it. ⇒ **parallel agents mutually invalidate each other's fingerprints**, and an agent killed mid-run leaves the directory **mid-write** for the next one.

So the suspect fits the timing but is **not confirmed**. **Reproduce it before fixing it** — run `--test lints` in two worktrees concurrently and capture the name.
