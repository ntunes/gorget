  **THE ORDERING, regenerable in one command:**

      grep -n 'validate_resource_sites_all\|validate_move_follow_through\|validate_drop_pre_rebind\|validate_consume_sites\|module.fn_param_abis = ' src/ir/lowering/mod.rs

  → the four validators run at **1751 / 1846 / 1880 / 2019**; `module.fn_param_abis = ctx.fn_param_abis.clone()` is at **2266**. **Every reader precedes the writer.**

  **MEASURED, not read off the source.** A temporary `eprintln!` in `for_each_consume_site`'s `Instruction::Call` arm, on a two-function program with ordinary by-value internal calls:

      A2ABI callee=gorget_string_clone_to_owned abis=false map_len=0

      A2ABI callee=wrap                         abis=false map_len=0
