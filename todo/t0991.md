  `v.fold(<non-constant String>, (acc, e): acc + e)` does not compile on C.**
  ```gorget
  String mk(String a, String b):
      return a + b

  void main():
      Vector[String] parts = ["a", "b", "c"]
      String joined = parts.fold(mk("<", ""), (acc, e): acc + e)
      print(joined)          # intended: <abc
  ```
