- **🆕🐛 [MED — Core #9 LANE LAG, opened 2026-08-29 by R47 Track E2's own fix; source-verified, not yet run-measured on the self-host lane] The self-host leaks the ITERATOR OBJECT that `for x in <user Iterable>` mints; Rust gg no longer does.** `lower_for_iterator` (`tests/fixtures/self_host_lowerer/lower_loops.gg:1079-1083`) mints the iterator into a fresh local — `iter_local = add_local(&ctx, iter_type_tid, None)` then `emit(&ctx, GICallExtern(iter_local, iter_fn, iter_args))` — and **never calls `register_local_for_drop`** on it. `iter()` returns the iterator BY VALUE, so the loop owns it; nobody frees it.
  - **THE RUST LANE CLOSED THIS SAME CELL** in R47 Track E2 (`src/ir/lowering/stmts/for_loops.rs`, the owned branch of the iterator bind, routed through `bind_owned_for_drop(..., LoopOwned::ByValue)`). The Rust-lane shape is pinned by `tests/fixtures/security/foriter_iterobj_int_elem_leak.gg` (`security_safe_no_leak`, RED-verified pre-fix at 146 bytes in 3 allocations, 3/3 runs). That fixture lives under `tests/fixtures/security/`, which `runtime_parity_corpus` does NOT scan (it reads only top-level `tests/fixtures/*.gg`, `tests/integration.rs::runtime_parity_corpus`), so this lag is a real divergence and not corpus inflow.
  - **THE OTHER TWO CELLS DO NOT LAG — check before widening the fix.** The self-host's ELEMENT binding is already handled, by a different and arguably better design: it registers the whole `Option` wrapper (`register_local_for_drop(&ctx, step_local, opt_ret_tid, &gmod)`, `lower_loops.gg:1135`) AND registers the bound element at `bind_for_local`. And the self-host's direct-Iterator branch already reuses `coll_local` itself (`lower_loops.gg:1079`) rather than a shallow copy, so it does not have the Rust lane's stale-copy defect.
  - **Fix shape:** register `iter_local` for drop in the ENCLOSING scope immediately after the `GICallExtern`, guarded by `is_droppable_type` — NOT inside the loop drop scope pushed further down (`push_drop_scope(DSK_LOOP)` at `:1131`), which would free the iterator at the end of iteration 1 and make every later `next()` a use-after-free. Only the `has_iter` branch: the `else` branch aliases `coll_local`, which the source still owns.
  - **Measure it before and after** with a self-host-compiled build of the Rust-lane fixture under `detect_leaks=1` (`LSAN_OPTIONS=use_stacks=0` — the default configuration under-reports); a `detect_leaks=0` run and a stdout check are both structurally blind to this class.
