- **🆕🐛 [HIGH — Core #9 LANE DIVERGENCE, under-rejection: self-host ACCEPTS a D4/D12 drop-tainted copy that Rust rejects] `infer_expr_type`'s `EFieldAccess` arm has no `RTGeneric` case, so the D12 gate is blind to a generic struct's fields.**
  ```
  struct R: int id
  equip R with Drop:
      void drop(!self): print("bye")
  struct Holder[T]:
      R r
      T payload
  Holder[int] h = Holder[int](R(1), 2)
  v.push(h.r)          # position 3, live drop-tainted field place
  ```
  → Rust gg: `error[E_MoveWithoutOperator]`. Self-host driver: **rc=0, emits C.** Measured at HEAD on both lanes.
  This is the under-rejection class D12 exists to close — a bare copy of a live drop-tainted place gives two owners of one resource and the drop runs twice. The equivalent CONCRETE-struct shape rejects correctly (`d12_drop_purity/pos3_field_place_reject.gg`), so the discriminating axis is the object's `ResolvedType` being `RTGeneric`.
  ⚠ **THE ASYMMETRY IS THE TELL, AND IT IS NOW PINNED.** R48 Track P moved the sibling D53 gate `reject_single_owner_init` onto the STRUCTURAL `lvalue_value_type`, which *does* have an `RTGeneric` arm — so the unique-lock analogue of this exact shape now rejects (`d53_unique_lock/mutex_generic_struct_field_push_reject.gg`) while the drop-taint one still slips. Two gates, one place shape, opposite verdicts.
  **Two candidate fixes, and they are NOT equivalent — pick deliberately.**
  1. *Add the missing `RTGeneric` arm to `infer_expr_type`.* Narrow at the call site but WIDE in blast radius: `infer_expr_type` is the type checker's own inference, so a new arm changes `expr_types` for every generic-struct field access in the compiler, not just the safety walk.
  2. *Move `reject_tainted_place` to `lvalue_value_type`*, mirroring the Rust twin (`tainted_place_name` → `lvalue_value_type`, `src/semantic/safety/check_expr.rs:164-166`) — the faithful shape, and the one this file's own war story mandates (`typecheck.gg:1437`: *"structural `lvalue_value_type` only — NEVER `infer_expr_type`"*). **But it is NOT a free swap**: at all 10 shared consume sites `reject_tainted_place` runs one line BEFORE `reject_single_owner_init` on the SAME expression (pairs 2280/2283 · 2330/2333 · 2652/2656 · 2711/2714 · 2837/2838 · 2846/2847 · 2855/2856 · 2859/2860 · 2890/2892 · 2911/2913), so since Track P it is the ONLY remaining full-inference call there and still carries the `DkNoFieldFound` diagnostics (`infer.gg:429`, `:465`) and the `types.expr_types` writes. Converting it DELETES those outright at 12 sites. **Any conversion owes its own diagnostic-delta check on ill-typed programs.**
  ⊕ Note it is NOT a cost bug: this probe takes `TypeTable &types` and merely re-borrows, so no table is materialised — it is cheap today and the clone ratchet will not notice either fix.
