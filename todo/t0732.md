  - **WHY R47 TRACK D1 DID NOT FOLD THIS IN, structurally rather than as a scope cut.** Rust rejects the two receiver kinds from TWO DIFFERENT BRANCHES of the EMethodCall arm, with different machinery. The `base_name is None` branch (a PRIMITIVE receiver) consults a small fixed method table per primitive — that is the branch D1 mirrored as `typecheck.gg::reject_no_method_on_primitive`. The `base_name.is_some()` branch (a NOMINAL receiver) runs `has_inherent_only_impls` plus the D36 auto-deref decision procedure for `Guard`/`ReadGuard`/`WriteGuard`/`Box` wrappers and the `NonDerefContainer` rejects (`src/semantic/typecheck.rs`, the `Expr::MethodCall` arm). The self-host has neither the per-collection builtin table nor the wrapper rules, so this is a different fix, not another site of the same one.
  - **THE TYPING HALF IS ONE EDIT, AND IT MUST BE MEASURED BEFORE IT LANDS.** Withhold the String-returning ladder arm (`infer.gg`, the `to_lower`/`to_upper`/`trim`/`lower`/`upper`/`strip`/`replace`/`join`/`repeat` arm) when the receiver resolves to `RTDefined`/`RTGeneric`. ⚠ `join` alone belongs to THREE receivers in the Rust oracle — String, `Thread[T]` → `T`, and `TaskGroup` → `void` — so the withhold needs a `TaskGroup` arm alongside the `Thread` arm D1 added, and `tests/fixtures/async_task_group.gg:8` calls `group.join()`. Whether NO_TYPE alone stops the CC-FAIL is unmeasured; it may still need the reject.
  - **THE INSTRUMENT.** Apply the withhold, rebuild the self-host driver, and run the accept/reject + emitted-C census over the corpus: for every `tests/fixtures/*.gg` and `spectests/run/*.gg`, run `driver <f> lib --emit-c` and diff the verdict AND an md5 of the emitted C against the pre-change driver.
