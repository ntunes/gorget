- **🆕🧹 [MED — NAME-MATCHING at a link decision + real OVER-LINKING; found 2026-08-18 by the Track-F executor while closing an undeclared-CI-dependency blocker, orchestrator-verified] `add_sdl_flags` decides which SDL sublibraries to link by `contains()` on the GENERATED C SOURCE, and the predicate is ALWAYS TRUE.** `src/main.rs:208-209`: `let needs_image = source.contains("GORGET_USE_SDL_IMAGE"); let needs_ttf = source.contains("GORGET_USE_SDL_TTF");`. Those strings are the `#ifdef` GUARD NAMES spelled inside `src/backend/c/runtime/sdl_runtime.c` (**4 occurrences**, verified), so every SDL program's emitted source contains them whether or not it touches images or fonts. Measured with a logging `CC` wrapper: a six-line `sdl_init`/`sdl_quit` program links `-lSDL2 -lSDL2_image -lSDL2_ttf -lm -lpthread`. **TWO defects:** (1) **CLAUDE.md "No name matching"** — a link-time routing decision spelled as a substring test over generated text, exactly the shape the rule forbids; the reference-grade fix is a typed flag on the declaration set at the source (which `xtd.sdl` symbols the program actually imports), read via an accessor. That is why the examples build gate needs all three dev packages in CI rather than just `libsdl2-dev`.
