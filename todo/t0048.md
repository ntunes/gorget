Chosen over a `# fmt: skip` magic comment because attributes are already validated against an allowlist and unknown ones are rejected (`E_UnknownDirective`; the allowlist is at `src/semantic/mod.rs:219` inside `validate_attributes` at `:204-231` — `:165-200` is the SEPARATE `directive` mechanism, do not cite it for this), so a typo FAILS THE BUILD instead of silently doing nothing. ⚠ **That rationale is FALSE TODAY and fixing it is part of the track: `gg fmt` runs NO semantic validation** (`src/main.rs:3540` calls the parse-only `format_source_result`), so the SWEEP eats the file long before any build fails — the check must run on the path `gg fmt` actually takes — the silent-no-op class this round ruled against three times; rustfmt (`#[rustfmt::skip]`) is the precedent, while Black/Prettier/clang-format use comments only because their languages lack a validated annotation at those positions.

  **Why it blocks A2:** the bulk sweep is a ONE-WAY flattening of hand-built structure.
