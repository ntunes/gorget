  - **VERIFIED at `f3feea79`:** `grep -rn '\.call_indirect(' src/` → empty; the rustc-rename witness (rename the definition line, count `E0599`s) yields **0** sites. Meanwhile `Instruction::CallIndirect` is fully plumbed — constructed in `src/ir/transforms/shared_async.rs`, and lowered in `src/lir/lower/insts.rs` — through liveness, validate and the printer.

  - **THE MIGRATION POINT NOW EXISTS.** R47 Track B routed all nine arms through `LoweringContext::call_indirect_tracked` (`src/ir/lowering/context.rs`), so the change of representation is now a single-function edit plus the LIR/BIR/backend work behind it, rather than nine scattered ones. Whoever takes this should start there and check what `insts.rs` promotes by name today.
