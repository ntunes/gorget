- **🆕🛡 [MED — A PIN REGENERATED FROM THE ARTIFACT IT PINS IS A MIRROR, NOT A GUARD; found 2026-09-04 by R49 Track INT's first brief-review while checking whether the re-derivation procedure could catch its own class (Six Questions #2)]** Four `assert_eq!`s pin the leak allowlist: `LEAK_CLASS_PAIRS`, `LEAK_RECORDS`, `LEAK_LOOSE_SIGNATURES`, `UNCITED_LEAK_CLASS_PAIRS` (plus `LEAK_CEILING`). Each has a `figures.db` row whose `regen` **reads the allowlist**. So the normal workflow — edit the allowlist, regenerate the constants — **disarms every one of them in the same motion.**
- **REGENERATE THE COUPLING WITH:** `grep -n "^row = sanitize.leak" scripts/figures.db` then read each row's `regen`; and `grep -n "pairs, LEAK_CLASS_PAIRS\|records, LEAK_RECORDS\|loose, LEAK_LOOSE_SIGNATURES\|uncited, UNCITED_LEAK_CLASS_PAIRS" tests/lints.rs` for the four asserts.
- ⭐ **THE CONCRETE FAILURE:** drop a `*N+` loose marker from a row and `LEAK_LOOSE_SIGNATURES` **would** have caught it — but regenerating the constant sets it to the new value and the tree is green. Same for a class silently added to an existing row (`LEAK_CLASS_PAIRS`), a raised count (`LEAK_RECORDS`), a lost citation (`UNCITED_LEAK_CLASS_PAIRS`).
- **WHAT SURVIVES A REGENERATION IS ONLY THE *SHAPE* CHECKS** — the duplicate-stem assert, the empty-column-2 assert, and the dead-citation assert. Those catch a malformed row. **None of them catches a well-formed WRONG row**, which is the whole class here.
- ⚠ **THIS IS NOT AN ARGUMENT AGAINST REGENERATING.** The constants genuinely must move when the allowlist legitimately moves. The defect is that there is no second, independent witness — every pin traces to the same artifact.
- ⭐ **REFERENCE-GRADE SHAPE (Core #6):** the guard must not read the constants at all. Make the allowlist's derivation a committed, re-runnable script (union + `verdicts.tsv` → allowlist) and lint that a fresh regeneration produces an **empty diff**. R49 Track INT ships that for **column 2 only**, as part of its own procedure. **This item owns the residue:** column 3 citations, the `+` markers, and the four constants remain mirror-pinned.
- **SCOPE NOT MEASURED:** whether other `figures.db` rows have the same self-referential shape is unchecked. The census is `grep -n "^row = " scripts/figures.db` cross-read against each `regen`'s inputs; a row whose `regen` reads the file its `mirror` lives in is the signature.
