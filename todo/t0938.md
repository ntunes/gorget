- **🆕🐛 [MED — COMPILER ICE (panic, not a diagnostic) on syntax the language ratifies] `Some(^h)` where `h` is a `Callable` local panics the compiler.**
  ```
  Callable[int(int)] h = (int x): x + 1
  Option[Callable[int(int)]] o = Some(^h)
  ```
  → `thread 'gg-main' panicked at src/ir/lowering/mod.rs:2144:17: Tier 2a consume-site violation ... EnumInit(Some, arg #0) — untracked source consumed`. No binary is produced.
  `^` is the RATIFIED move sigil (D27) and enum-init is a ratified consuming position, so the user wrote the spelling the language asks for and got a crash. An ICE is never an acceptable answer to legal source: either the move is accepted, or it is REJECTED with a diagnostic (Core #10).
  ⊕ Note the interaction with `t0936`/`t0937`: the bare `Some(h)` form on the same value hits `t0937`'s never-constructed closure instead, so BOTH spellings of this one line are currently broken by different defects.
