- **🆕🔬 [MED — A `WRONG` CELL THAT STARTS PRINTING A *DIFFERENT* WRONG VALUE IS INVISIBLE TO THE MAP, and topic 30 is 237 cells whose entire defect class is a wrong VALUE. Filed with the corpus that makes it material.]** The scorer's three branches are `base == good && bucket != good` (REGRESSION), `base != good && bucket == good` (PROGRESS), and `base != bucket` (DRIFT). A row at `base == bucket == WRONG` matches none of them, and nothing compares the printed output against anything but the `expected` column. So `WRONG:777 -> WRONG:140737488355328` — a wrong value becoming a leaked address — is **not a regression, not a progress row, not a drift, and not a divergence.**

  ⛔ **AND THE OBVIOUS FIX IS THE ONE THE MAP'S CHARTER FORBIDS.** Recording the printed value as part of the baseline is one keystroke from "update the expectation to match what the compiler prints", which is the first thing the module docstring rules out — *"that pins a bug as canonical, which is the worst outcome available here"*. The distinction that makes a fix admissible is that a WITNESS column is not an EXPECTATION column: `expected` stays hand-derived and untouched, and a separate recorded-output column would be compared only against ITSELF, never against `expected`. The `actual` column already exists in the schema and is written by nothing, so the shape is available; what is missing is the decision that it may be.

  ⚠ **THIS IS NOT WHAT THE DRIFT RATCHET'S STAGE 3 CLOSES, and saying so was an error worth recording.** Promoting drift to fatal (`FATAL_DRIFT_TOPIC_PREFIX`, landed for topic 30) makes a BUCKET change gate. It does nothing at all for a value change inside one bucket, because the drift branch's own condition is `base != bucket`. `t0993` owns the bucket-level census; this is the level below it and the two do not overlap.

  ⭐ **WHAT ALREADY COVERS PART OF IT, so the severity is MED and not HIGH.** The most alarming direction — a wrong value becoming a *memory-invalid* one, which is what `D52` obligation (ii) predicts for this family (*"a bug there is a UAF, not a wrong answer"*) — DOES change a bucket, on the `asan` column, and topic 30 is baselined on that lane with drift fatal. The uncovered residue is a value-only change: still-valid memory, still-wrong answer, differently wrong. On a 237-cell topic whose whole subject is which value a place reads, that residue is not negligible.
