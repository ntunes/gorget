- **🆕🚨 [HIGH — A ROUND-CLOSE GATE IS RED ON THE R47 INTEGRATION BRANCH. Found 2026-08-29 by R47 Track D3a when it merged the integration branch; NOT caused by that merge.]** `cargo test -p ggdef` fails:
  ```
  cow_alias_spelled_view_via_first_getter.gg: frontend error (STOP-and-report):
  elaboration error @ 867..880: method `.first()` is outside the phase-0 subset
  ```
  Reproduce with `cargo test -p ggdef --release corpus_b_all_match`. Verified pre-existing on the integration branch: the fixture arrives with `e7967d57` ("fix(cow): a collection identity names the storage owner, not the spelling", the `t0703` fix), and `git merge-base --is-ancestor e7967d57 main` holds.
- **WHY IT IS RED RATHER THAN EXCLUDED.** `corpus_b.rs` runs the ENTIRE `cow_*` / `deadwrite_*` corpus minus a by-name `EXCLUDE` list, so **every new `cow_*` fixture is opted IN by default**. `e7967d57` added six (`cow_alias_severed_by_root_reassign_then_view`, `cow_alias_spelled_element_field_borrow`, `cow_alias_spelled_view_literal_payload`, `cow_alias_spelled_view_survives_root_growth`, `cow_alias_spelled_view_via_first_getter`, `cow_alias_view_spelling_invariance`); the `.first()` one is outside ggdef's subset and got neither an `EXCLUDE` row nor a filed subset gap.
- **⚠ DO NOT JUST ADD THE EXCLUDE ROW WITHOUT DECIDING — the harness itself says STOP-and-report**, and Core #9 requires an out-of-subset shape to get *"a note + a filed subset gap"*, not a silent exclusion. Two defensible dispositions, and it is a real choice: **(a)** teach `elaborate` the `.first()` getter, if it is in phase-0's spirit (it is an ordinary sequence getter, and the corpus already leans on `.get()`); **(b)** `EXCLUDE` it with the reason recorded, exactly as the three generic-equip cow fixtures are, and file the subset gap. Whoever takes this should also check the OTHER five for latent subset trouble rather than fixing the one that happened to fail first.
- **THE GAP THIS EXPOSES IS THE REUSABLE FINDING:** a track can add a `cow_*` regression fixture and redden a lane it never ran, because corpus membership is implicit (glob-minus-exclusions) while the subset is not. A guard that lists each new `cow_*` fixture's ggdef disposition at add-time — the way `fmt_suite_layout_census_is_complete` pins its directory against a named list — would convert this class into a compile-time decision instead of a round-close surprise.
