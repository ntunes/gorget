- **🆕🚨 [MED — A LEAK IN A BEGINNER-TUTORIAL SHAPE, AND IT IS REDDING THE ROBUSTNESS MAP'S FIVE-LANE STEP TODAY. Pre-existing at `224da7ae7`; found by R50 Track G while running that step as a gate, NOT introduced by it.]** `tests/fixtures/robustness_map/cells/ex_char_frequency.gg` — a character-frequency histogram, twelve lines, nothing exotic — leaks under ASan:

  ```
  Direct leak of 2 byte(s) in 1 object(s) allocated from:
      #1 __gorget_global_alloc_fn
      #2 str_alloc_copy
      #3 gorget_string_clone_to_owned
      #4 main
  ```

  Reproduce (deterministic, both the map and by hand):
  ```
  python3 scripts/robustness_map.py --lanes asan --topic "14 classic exercises"
  ./target/debug/gg build tests/fixtures/robustness_map/cells/ex_char_frequency.gg --sanitize -o /tmp/x
  ASAN_OPTIONS=detect_leaks=1 /tmp/x
  ```

  **THE CELL'S asan BASELINE SAYS `WORKS`, so the map reports it as a REGRESSION and exits 1.** That is the gate working: something moved this cell from clean to leaking since its baseline was last reviewed, and nothing else in the tree noticed — `scripts/sanitize_sweep.sh` walks only top-level `tests/fixtures/*.gg`, and `robustness_map/` is an explicit `OUT` row in `tests/sanitize/CORPUS_MANIFEST.txt` precisely because the map has its own asan lane. This is that lane earning its place.

  **THE SHAPE.** `for ch in s:` over a `String` binds each character; the frame's clone is `gorget_string_clone_to_owned` at the loop head in `main`. `freq.put(ch, prev + 1)` is a consuming position and takes its own copy for the Dict, so the loop-head copy is dead the moment the body ends — and it is never registered for drop. Core #3: *register ownership at the value's birth*; the producer here is the character-iteration loop head, not the `put`.

  ⚠ **DO NOT "fix" it by making `put` steal the loop variable.** The loop variable is live across iterations of the enclosing loop by construction, so the move-eligibility rule says clone; the defect is the missing drop registration on the loop-head copy, not the clone at the consuming position.

  ⊕ **Only 2 bytes, once — but the severity is not the byte count.** It is a leak in the most ordinary shape a beginner writes, on the corpus that exists to measure exactly that, and it is currently the reason a CI step cannot go green.
