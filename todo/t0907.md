- **🆕🚨💥 [HIGH — MEMORY-UNSAFE, `gg check` rc 0, and BOTH VALUE LANES PRINT THE RIGHT ANSWER; found 2026-08-31 by R48 Track D2 while ASan-sweeping its own fixture net] TWO refcount-ARITHMETIC boundaries drop a handle they never increfed.** Both surfaced only once `t0840` made `Vector[Shared[T]]` runnable at all — before that the programs SEGFAULTed before reaching them. Neither is the `t0840` marshalling class: the bytes go to the right places, the retain/release COUNT is wrong.
  - **(a) CONTAINER CLONE.** `outer.push(inner.clone())` where `inner: Vector[Shared[int]]`. `gorget_array_clone` (`runtime_array.c`) memcpys the element bytes and then calls `elem_clone` on each slot IF the array carries one — the hook that makes a `Vector[String]` clone deep. `elem_clone_fn_for_type` (`src/lir/lower/types.rs`) reads `TypeMetadata.clone_inplace_fn`, and the refcount TypeDefs (`ensure_shared/weak/channel_type_def`) set `clone_fn` but NOT `clone_inplace_fn` — and no `{T}__clone_inplace` wrapper is emitted for them. So the slot stays NULL, both arrays alias the same handles with the refcount unchanged, and both drop: `AddressSanitizer: heap-use-after-free` in `gorget_shared_drop` ← `Shared__int64_t__drop` under TWO nested `gorget_array_free` frames. **DISCRIMINATOR: the identical `Vector[Vector[String]]` shape is ASan-clean**, because `GorgetString` carries `clone_inplace_fn`.
  - **(b) DICT VALUE-BIND ITERATION.** `for (k, v) in d` over `Dict[String, Shared[int]]` over-releases, so `gorget_map_free` walks its second entry into an already-freed control block: same ASan signature, one `gorget_map_free` frame. **TWO DISCRIMINATORS, both measured:** the identical loop over `String` VALUES is clean, AND `for h in v` over a `Vector[Shared[int]]` is clean — the Vector element bind takes the `Ptr`-borrow path in `src/ir/lowering/stmts/for_loops.rs` (gated on `is_resource_type`, which a refcount handle fails, but the Vector path reaches the borrow another way) while the Dict value bind does not. So this is ONE iteration bind, not a general iteration defect.
- **THE SHAPE OF THE FIX.** (a) is a metadata + wrapper pair: set `clone_inplace_fn = "{mangled}__clone_inplace"` on the refcount TypeDefs beside the existing `set_refcount_clone_fn` single writer, and emit `static inline void X__clone_inplace(void* p) { *(X*)p = gorget_<family>_clone(*(X*)p); }` next to the existing `X__clone` in `emit_shared_wrapper` / `emit_channel_wrapper` (`src/backend/c_lir/helpers.rs`). ⚠ Both lanes compile that helper text, so ONE producer covers C and LLVM — verify, do not assume. (b) is the Dict value bind reaching the same borrow disposition the Vector element bind already has.
