- **🆕🐛 [HIGH — SILENT WRONG OUTPUT, BOTH BACKENDS, ORACLE-ADJUDICATED, `gg check` CLEAN; found 2026-09-05 by the R50 Track G scout while measuring a 792-cell generated matrix]** An `&`-param bind loses value semantics in any nested block.

  ```gorget
  void probe(Vector[int] &v):
      Vector[int] c = v        # value bind
      if 1 == 1:
          v.set(0, 777)        # mutation one block down
      print(c.get(0).unwrap())
  ```
  **C `777` · LLVM `777` · ggdef `10`.** Straight-line mutation is **correct**. **6 of 8 payloads.**
  ⭐ **REPRO INLINED 2026-09-06 (R51 close) — it was cited only as `/tmp/scoutG/param_min.gg`, which does not
  survive round close.** The item is now self-contained:

  ```gorget
  void probe(Vector[int] &v):
      Vector[int] c = v
      if 1 == 1:
          v.set(0, 777)
      print(f"{c.get(0).unwrap()}")
  void main():
      Vector[int] q = [10, 20]
      probe(&q)
  ```
  The `if 1 == 1:` is load-bearing — it is what puts the write inside a **branch**; the straight-line form of the
  same program is correct on all three lanes.

  ⭐ **IT IS NOT THE BARE-PARAM FAMILY, and that is why it was never filed.** [[t0750]]'s own discriminator
  paragraph **excludes** `t0122`–`t0127` / `t0344` / `t0556` because that family's symptom is *"a per-iteration
  throwaway of a private copy"*. **This symptom is different: the bind silently degrades to reference
  semantics.** The exclusion that correctly separated those items also hid this one.

  **Same family as [[t1362]]** — *"a view is not severed when its source is mutated"* — but a **different
  SOURCE shape**, and the family's write-site set is 13 sites in three files
  (`grep -rn "set_cow_borrow_source(builder" src/`). ⚠ **Do not assume `t1362`'s fix reaches it; the two
  broken source shapes measured so far sit at different write sites.**

  ⊕ **Sibling finding from the same sweep, equally unfiled and worth its own cell:**
  `String c = v.get(0).unwrap()` on `Vector[String]` → C `abZ`, ggdef `ab`. ⭐ **That is the EXACT program
  `docs/language-design.md` §3.5 uses to explain the lazy escape** — *"`String s = v.get(0).unwrap()` followed
  by `grow(&v)` … the compiler inserts a guarded copy and the program is accepted."* **It is accepted, and the
  guarded copy is not inserted when the mutation is one block down.** It diverges on the `String` payload
  **only** (1 of 8), so **any payload-sampled fixture set misses it** (Core #12).
