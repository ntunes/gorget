- **🆕🔧 [LOW — LATENT, NOT LIVE. A structural hazard in a sibling of the ledger R50 Track E deliberately did not build. Found 2026-09-05 by Track E's brief-review pass 1 (N8), named fix-or-file, filed.]**

  `printf_str_temps: Vec<SlotId>` is a field on `FuncLowering` (`grep -n 'printf_str_temps' src/lir/lower/mod.rs src/lir/lower/insts.rs`). `lower_printf_args` PUSHES into it at the `gorget_bool_to_str` arm; the printf-like branch of the extern-call emitter DRAINS it with `std::mem::take` after `emit_extern_call` returns. Two different functions, coupled through mutable state on the lowering.

  ⭐ **IT IS SOUND TODAY, AND THE REASON IS AN ACCIDENT OF SHAPE, NOT A GUARD.** Push and drain sit in ONE straight-line match arm with no `?`, no early `return` and no conditional between them, so no path can push and skip the drain. Nothing enforces that. A `?`-bail added anywhere between them — the shape `try_emit_vector_each_hof` already has at `result_elem_name.clone()?` — orphans the temp into the ledger, and the NEXT printf-like call in the same function emits a `gorget_string_free` for a slot that belongs to a different call, in a different block.

  **THE REFERENCE-GRADE SHAPE IS ONE FILE OVER, SHIPPED.** R50 Track E made `wrap_closure_call_args` return a `#[must_use] ClosureArgTemps` VALUE rather than write a ledger field, precisely so a bail-out drops the temps instead of donating them (`grep -n 'struct ClosureArgTemps' src/lir/lower/operands.rs`). Do the same here: have `lower_printf_args` return `(Vec<ValueId>, Vec<SlotId>)` — or a `#[must_use]` newtype — and drain from the local. The field, and its comment, go away.

  ⚠ **THE GRADUATION OWES A BYTE-IDENTITY PROOF.** This is a pure extraction and must be shown to be one: emitted C (`gg build --emit-c-lir`) byte-identical before and after on a fixture that prints a `bool` (the only producer arm) plus one that makes two printf-like calls in one function. Anything else is a behaviour change wearing a refactor's clothes.

  ⚠ **NOT REPRODUCIBLE, so no `known_gaps` repro is owed** (Task Continuity's exemption): there is no program today whose behaviour is wrong. The defect is that nothing stops the next edit from making one.
