- **🆕🚨 [HIGH — SELF-HOST CC-FAIL: a generic FREE function's body is never emitted, so the emitted C does not LINK; found 2026-08-31 by the R48 Track C output review, root-caused and minimised by the executor] `T firstOf[T](Vector[T] v)` called as `firstOf(v)` emits the CALL and never the monomorphized BODY** — `cc` reports `undefined reference to 'firstOf'`. Rust gg and ggdef both run it correctly.
- **THE DISCRIMINATOR IS WHERE THE TYPE PARAMETER LIVES, and it is measured, not argued.** All four cells run against a driver built from the pre-fix compiler, so none of this is R48 Track C's doing:

  | shape | type param reachable from | self-host |
  |---|---|---|
  | `T id[T](T x)` — `id("a")`, `id(7)` | a BARE argument | **links, prints `a` / `7`** ✅ |
  | `T firstOf[T](Vector[T] v)` — `String` elements | inside `Vector[T]` | **CC-FAIL** |
  | `T firstOf[T](Vector[T] v)` — `int` elements | inside `Vector[T]` | **CC-FAIL** |
  | `void bump[T](Vector[T] &v, T x)` | inside `Vector[T]` | **CC-FAIL** |

  ⇒ It is NOT the `&` sigil, NOT the element type, and NOT the return type. It is the type parameter being reachable only through a CONTAINER type argument. `discover_generic_calls_stmts` / the `generic_instances` collection in `lower.gg` matches the bare-`T` parameter shape and misses the nested one.
- **PRE-EXISTING, and the proof is the size of the repro.** A 6-line program with no view, no realloc, no equip and no CoW machinery of any kind reproduces it. It surfaced now only because R48 Track C's path-axis net was the first thing in the corpus to put a generic free function on the self-host lane.
