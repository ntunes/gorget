- **🆕🚨💥 [CRITICAL — TWO Book-Ch16 `Shared[T]` IDIOMS ARE MEMORY-UNSAFE ON THE C LANE, both at rc 0 from `gg check`; found 2026-08-30 by R47 Track F4a when the new verdict classifier stopped grading signal deaths as `TRAP`]** Both cells are six lines, both are the documented spelling, and both were sitting in the robustness map recorded as `TRAP` — "the program failed loudly, as expected" — because the map's run-side verdict read only `returncode != 0`.

  - **(a) A `Shared[T]` PASSED TO A PLAIN FUNCTION IS FREED BY THE CALLEE.** `tests/fixtures/robustness_map/cells/sh_pass_to_function.gg`: `int read_it(Shared[int] s): return s.get()` called as `read_it(s)`, then `s.get()` again in the caller → **rc -11 (SIGSEGV)**; under `gg build --sanitize` it is `AddressSanitizer: heap-use-after-free` in `gorget_shared_get_ptr` ← `Shared__int64_t__get` ← `main`. ⚠ **This contradicts the compiler contract directly.** `AGENTS.md` § "Ownership at Consuming Positions" names `Shared`'s family among the single-owner-by-design carve-outs and says of them: *"At a plain function / method call these types are simply borrowed, so no operator is needed."* The cell's own header quotes that rule. So the callee must not be dropping anything — the caller keeps its handle.
  - **(b) A `Vector[Shared[T]]` OF CLONED HANDLES READS A GARBAGE POINTER.** `tests/fixtures/robustness_map/cells/sh_vector_of_shared.gg`: three `all.push(s.clone())` then `all.get(1).unwrap().get()` → **rc -11**, ASan `SEGV on unknown address 0x17d7d7e7d7d7d7d7` in `Shared__int64_t__get` ← `main`. The address is not a poison pattern — it is data being read as a pointer, i.e. the element layout at the read disagrees with the layout at the push. This is the "many owners" case `docs/book/` Ch16 exists to teach.

- **WHAT DISCRIMINATES THIS FROM THE FILED `Shared` WORK.** `todo/t0612`'s residual is `Shared[Callable[T]].get()()` — an INVOKE-chain lowering gap whose own text records *"there is NO heap-overflow/UAF/SEGV"*. `todo/t0406` is the non-identifier-callee `&`-sigil class. Neither covers a `Shared[int]` — no callable, no closure, no sigil — and `grep -rn 'gorget_shared_get_ptr' todo/` is empty at filing. These are the plainest possible `Shared` programs.

- **⚠ THE TWO CELLS ARE PROBABLY ONE DEFECT SEEN TWICE, BUT DO NOT ASSUME IT.** (a) frees at a borrow position; (b) mis-reads a pushed element. Both land in `Shared__T__get`, and a refcount that the callee decrements would explain (a) and, via the `.clone()` handles, could explain (b) — but (b)'s garbage address looks like a LAYOUT fault rather than a lifetime one. Measure both before calling either closed, and check the `^`/`.clone()` spellings of each.
