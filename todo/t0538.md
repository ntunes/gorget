### ⚖ PHASING AMENDED 2026-09-05 (owner-ratified) — `warn` MOVES OUT OF STAGE C

**The owner ratified this sequencing while ruling R2's direction** (*"I agree with your conditions"*,
2026-09-05). This item's phasing reads **A(summary+arg elision) → B(spec+fixtures) → C(knob, `warn` burn-down
before any `deny`) → D**. ⛔ **The `warn` half moves to ship WITH the analysis. `deny` stays where it is.**

**Two independent lines reached the same constraint, from opposite axes:**
1. **Cost axis (R50 Track F scout, from prior art).** MLKit's own retrospective names the **region profiler**
   as the single thing that made an inferred, invisible, non-rejecting memory optimization usable, and names
   *"given an apparent space leak, how would a programmer locate it?"* as what nearly killed the project. **An
   implicit-clone optimizer with no way to ask "why did this clone happen" is exactly that artifact.**
2. **Legality axis (R2's ruling direction).** *bare = snapshot* **UN-REJECTS**: a program that is a compile
   error today becomes **accepted with a silent O(n) clone inside a loop** — the worst possible place for an
   invisible cost. **The diagnostic is what keeps that honest.**

⭐ **This item's own internal constraint SURVIVES UNTOUCHED: §3 (the specified guaranteed-elision set) still
precedes any `deny` mode**, because without it `deny` pins user code to optimizer internals and every analysis
improvement becomes a potential breaking change. **The change is only that `warn` arrives with the analysis
instead of two phases later.**

⊕ **The instrument is largely BUILT, which is why this is cheap.** `--clones=sites-tsv=PATH` already emits
**file · line · column · type · REASON · bytes · symbol** per CloneId — e.g.
`0  <file>  5  12  Dict[int, int]  ReturnFromBorrow  144  gorget_map_clone`. Regenerate:
`./target/debug/gg run <getter fixture> --clones=sites-tsv=/tmp/x.tsv >/dev/null 2>&1; cat /tmp/x.tsv`.
⚠ **The gap is that it is a DUMP, not a DIAGNOSTIC** — nothing surfaces it to a user who does not already
suspect a clone. **`warn` is the surfacing, not new analysis.**
⚠ **Do not read `--clones=stats` as the instrument** — it prints an opaque `[clone-site] #0=10` with no source
location, and mistaking it for the whole story is how the orchestrator wrongly reported that clones could not
be located at all.
