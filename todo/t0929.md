- **🆕🐛 [MED — Core #10 lower-or-reject + Core #9 accept/reject LANE DIVERGENCE, on the self-host. Filed by R48 Track β, whose brief dispositioned this cell DEFER-with-reason: same error code, different validator, different surface.] The self-host performs NO item-ATTRIBUTE validation: `@nonexistent` on a struct is accepted and the attribute is discarded, where Rust gg rejects it with `error[E_UnknownDirective]`.**
  - **MEASURED at HEAD** on `tests/fixtures/unknown_attribute_error.gg`: Rust gg `gg check` → `error[E_UnknownDirective]: unknown directive `@nonexistent``, rc 1. Self-host lowerer driver → rc 0, `int main(` emitted. The fixture is a one-lane pin and says so in its own header.
  - **NOT the same class as `t0825`** (the directive validation R48 β closed), which is why it was deferred rather than absorbed: `validate_attributes` (`src/semantic/mod.rs`, called on `module.items` after the directive scan) checks a DIFFERENT surface — `@name` on struct / enum / function / test items, recursing into `Item::Module` — against a DIFFERENT allowlist, `{derive, tag, should_panic, skip, timeout}`. It shares only the `SemanticErrorKind::UnknownDirective` error kind, which is itself arguably a misnomer for the attribute half.
  - **FIX SHAPE.** A `validate_attributes` twin beside the new `validate_directives` in `tests/fixtures/self_host_typechecker/resolve.gg` (and `self_host_resolver/resolve.gg`), reusing the `DkUnknownDirective` DiagKind those files already carry, plus the module-recursion arm. ⚠ **CHECK FIRST whether the self-host parser even KEEPS the attributes**: `parse_module` collects `pending_derives` / `pending_skip` / `pending_should_panic` into typed locals and threads the test flags through `ITest`'s `with_names` as sentinel entries — an attribute it does not recognise may already be dropped at parse time, in which case the reject belongs in the parser and this is a losslessness fix first (see `t0928` for the same boundary).

Both are about the Rust lane and the formatter; this one is about the self-host accepting what Rust refuses.
