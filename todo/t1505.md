- **🆕🚨 [CRITICAL — A LATENT MISCOMPILE THAT ARMS ITSELF THE MOMENT THE ABI IS FIXED. Measured 2026-09-06 by R51 Track F's brief-review pass 2, with a built prototype.]**

  One decision — *"is this declared `Ref[T]` parameter passed as a pointer?"* — is **re-derived independently at FIVE sites**: `register_fn_sigs` param_types · `register_fn_sigs` abis · `register_equip_sigs` · `lower_generic_function` (**twice**) · the three `is_borrow_named` blocks. ⚠ **The `is_borrow_named` triple is the ONLY set that gets it right, and it does so by AST NAME-MATCHING (Core #2) precisely because the shared mapper lost the fact.**

  ⛔⛔ **THE CONSEQUENCE IS NOT A CLONE — IT IS SILENT WRONG OUTPUT.** With the write site corrected so `ParamABI` is `ByPtr` (which is what `[[t0952]]` needs), a **Gorget-bodied generic** `int len_via_ref[K,V](Ref[Dict[K,V]] m)` forwarding to an extern prints **`30` where pristine prints `3`**. `gg check` **rc 0**, run **rc 0**. Emitted C: the callee body does `__s1 = __v0; __v1 = &__s1;` handing a `GorgetMap**` to a `GorgetMap*` parameter, where pristine emits `__v1 = __s1`. **One indirection too many.**

  ⚠ **AND THE CURRENT CODE IS ONLY SAFE BY ACCIDENT (SIX-Q #6, measured):** the ABI stays `ByValue`, so the callee's inner call never reaches the by-ptr arm. **The bug is masked by the very defect `t0952` exists to fix.**

  ⛔ **NON-GENERIC CONTROL PRINTS `3` ON BOTH ARMS** — the shape is supported today and the regression is confined to the **monomorphized-generic** path.

  **INTENDED:** ONE shared accessor for the `Ref[T]`→pointer decision that all five sites read (Layering rules 3 and 4) — which also **retires the three `is_borrow_named` name-matching blocks through the accessor**. ⛔ **Any change that flips `Ref[T]` params to `ByPtr` MUST land the callee-side write-through IN THE SAME CHANGE, or reject the shape (Core #10).** Splitting them ships the miscompile.
