- **🆕🚨 [CRITICAL — A LATENT MISCOMPILE THAT ARMS ITSELF THE MOMENT THE ABI IS FIXED. Measured 2026-09-06 by R51 Track F's brief-review pass 2, with a built prototype.]**

  One decision — *"is this declared `Ref[T]` parameter passed as a pointer?"* — is **re-derived independently at FIVE sites**: `register_fn_sigs` param_types · `register_fn_sigs` abis · `register_equip_sigs` · `lower_generic_function` (**twice**) · the three `is_borrow_named` blocks. ⚠ **The `is_borrow_named` triple is the ONLY set that gets it right, and it does so by AST NAME-MATCHING (Core #2) precisely because the shared mapper lost the fact.**

  ⛔⛔ **THE CONSEQUENCE IS NOT A CLONE — IT IS SILENT WRONG OUTPUT.** With the write site corrected so `ParamABI` is `ByPtr` (which is what `[[t0952]]` needs), a **Gorget-bodied generic** `int len_via_ref[K,V](Ref[Dict[K,V]] m)` forwarding to an extern prints **`30` where pristine prints `3`**. `gg check` **rc 0**, run **rc 0**. Emitted C: the callee body does `__s1 = __v0; __v1 = &__s1;` handing a `GorgetMap**` to a `GorgetMap*` parameter, where pristine emits `__v1 = __s1`. **One indirection too many.**

  ⚠ **AND THE CURRENT CODE IS ONLY SAFE BY ACCIDENT (SIX-Q #6, measured):** the ABI stays `ByValue`, so the callee's inner call never reaches the by-ptr arm. **The bug is masked by the very defect `t0952` exists to fix.**

  ⛔ **NON-GENERIC CONTROL PRINTS `3` ON BOTH ARMS** — the shape is supported today and the regression is confined to the **monomorphized-generic** path.

  **INTENDED:** ONE shared **(TypeId, ParamABI) PAIR** accessor that every declared-param site reads (Layering rules 3 and 4).

  ⛔ **CORRECTED 2026-09-06 (R51 Track F pass 3) — THIS ITEM'S FIRST DRAFT PROMISED A RETIREMENT THAT IS NOT ACHIEVABLE, AND AN EXECUTOR WOULD HAVE BUILT FROM IT.** It said the accessor *"retires the three `is_borrow_named` name-matching blocks"*. **It cannot.** `Ref`/`MutRef` are **NAME-ONLY builtins** — no parser keyword, no declaration in `lib/std/`, and `Type::Named{name:"Ref"}` is the sole AST carrier. Total witness: `grep -rn '"Ref"' src/` → **8 hits**, all accounted for (the mapper ×3, `is_borrow_named` ×3, `safety/type_utils.rs`, one doc line). ⇒ **an accessor CENTRALISES the name match (Layering rule 4, resolve-once-write-through); it does NOT retire it.** Retirement needs a typed carrier that does not exist yet. ⊕ And two of the three `is_borrow_named` sites call the **immutable** mapper, so they cannot be re-driven off a TypeId until that axis is fixed first.

  ⛔ **AND ONE SHARED `Option<TypeId>` CANNOT SERVE THE SITES — there are TWO distinct failure modes:** immutable-mapper sites get `map_ast_type(Ref[T])` → `UNIT_TYPE` (**TypeId wrong AND ABI wrong**), while mutable-mapper sites already hold `Ptr(T)` and only the **ABI** is wrong, because `is_resource_type(Ptr(_))` is `false` → `ByValue`. A TypeId-only accessor is **measurably INERT** at the second kind.

  ⭐⭐ **AND THE CANONICAL ACCESSORS ALREADY EXIST AND ARE BYPASSED:** `ctx.resolve_param_type` and `ctx.compute_param_abi` (`src/ir/lowering/context.rs`), whose bodies are **hand-inlined verbatim** at four `generics/mod.rs` sites. **That is the write site Layering rule 3 points at** — a duplicated-body problem, not a missing-abstraction one.

  ⛔ **THE PAIRING RULE IS PER SITE-PAIR, NOT PER TRACK.** Fixing a caller-side ABI without its matching callee-side write-through re-arms this defect at that pair: measured, a generic **equip** method with the caller fixed and `lower_equip_method_with_subs` untouched prints **`1` for a 7-entry dict**. ⚠ **AND A 3-ENTRY FIXTURE — the size every probe in this family used — SITS GREEN OVER IT** (SIX-Q #6). **Size the fixture to distinguish, not to pass.**

  ✅ **IT IS FIXABLE IN-INCREMENT — Core #10's "reject the shape" is NOT required.** Measured prototype `/tmp/revF51p3_shapeX.patch`: the generic Gorget-bodied cell goes `30` → **`3`** with the full headline win intact (`map_clone` 801 → **0**, RSS 6104 → **1256**). ⛔ **Any change that flips `Ref[T]` params to `ByPtr` MUST land the callee-side write-through IN THE SAME CHANGE, or reject the shape (Core #10).** Splitting them ships the miscompile.
