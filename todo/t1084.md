- **🆕🚨 [HIGH — SELF-HOST LANE DEBT, Core #9: R49 Track M2 landed a semantic change on the Rust C and LLVM lanes and the self-host lane does not have it. Filed with the fix, not promised.]**
  - **THE MISSING PIECE.** Rust gg packs a `Box[Concrete]` into a `Box[Trait]` `{data, vtable}` pair at TWO layers: the LIR Assign/SlotStore coercion, and — as of R49 M2 — a GIR-level pack at every consuming position (`push`/`put`/`set`/`insert`/`fill`/`get_or_put`, `v[i] = x`, `d[k] = x`, ctor args, returns, captures). The self-host has **only the first**: `try_emit_trait_obj_construct` (`tests/fixtures/self_host_lowerer/lir_lower.gg`, called once), whose own comment says it mirrors `src/lir/lower/operands.rs`. There is **no GIR-level analogue at all**.

- **⊕ NEW AXIS CELL — THE CLOSURE RETURN, and it is the one that fails UNSAFELY. Measured 2026-09-04 (R49 Track T1, which EXPOSED it; not its cause).**
  - **THE CELL.** `tests/fixtures/box_trait_closure_return.gg` — `Callable[Box[Speaker]()] f = (): Box.new(Robot("R2"))`, then `f().speak()`. A **live, top-level, non-`#[ignore]`d corpus fixture**, green on both Rust lanes (`R2`), which is what discriminates it from every row above: those are all `known_gaps/` repros, this one is a committed regression cell.
  - **WHAT DISCRIMINATES IT FROM THE ROWS ABOVE:** the consuming position is a closure RETURN, not a collection consume, an index-assign or a struct field. Same missing GIR-level pack, an axis cell the enumeration did not have.
  - **⚠ THE FAILURE MODE ROSE FROM SAFE TO UNSAFE, and it is worth stating plainly.** Before the ambient-return port the self-host typed the closure `int64_t`, so the dynamic call emitted `int64_t__speak` and the program **failed at LINK** — `undefined reference to 'int64_t__speak'`, a build error nobody could ship. With the closure correctly typed `__gg_Box__Speaker` the program LINKS, and then SEGVs (rc 139) on the vtable dispatch. **A cell that failed loudly at build time now fails at run time.** The port is right — the return type it computes is the declared one — and the exposure is the point: the link error was masking a missing pack, not preventing one.
  - **THE EMITTED BODY, and it is worse than "unpacked":**
    ```c
    __gg_Box__Speaker __Closure_0__call(void* __p0) {
        __gg_Box__Speaker __s0 = {0};
        ...
        __v1 = __s0;
        return __v1;          // Box.new(Robot("R2")) never reaches the slot
    }
    ```
    The construction produces nothing the result slot receives; a ZEROED trait box is returned and `.speak()` dispatches through a NULL vtable. The other rows memcpy an unpacked concrete box; this one returns no box at all.
  - **⚠ NO GATE IN THE ROUND-CLOSE BATTERY OBSERVES THE RISE.** The robustness map has no entry for this fixture, `sanitize_sweep.sh` has no self-host lane, and the parity ledger is bucket-neutral (the row was already non-MATCH as CC-FAIL and stays non-MATCH as CRASH). **This item and its `#[ignore]`d pin are the only durable record** — without them a future round reads a green battery as "the SEGV is gone".
  - **⛔ THE MIRROR-SITE COUNT IS ONE, NOT FOUR.** Regenerate: `grep -rn 'try_emit_trait_obj_construct' tests/fixtures/self_host_lowerer/*.gg` → one definition (`lir_lower.gg:3535`) and one call site (`:3873`). Rust is the same shape (`grep -rn 'try_trait_object_construct' src/` → `operands.rs:931` + `insts.rs:32`), which is exactly why the GIR-level pack Rust added in R49 M2 is the missing half rather than a second opinion. *(A brief-review pass this round asserted the self-host mirrors the helper "at 4 sites"; it does not, and the correction matters because "4 sites but not this one" would read as a sibling-site omission when the truth is a whole missing layer.)*
  - **PIN:** `box_trait_closure_return_self_host`, `#[ignore]`d, asserting the intended `R2` on the self-host lane against the existing top-level fixture. Deliberately NOT a second copy under `known_gaps/` — the fixture already exists and is already enrolled in the corpus, so duplicating it would add a corpus row for a defect that already has one.
