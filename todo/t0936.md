- **🆕🐛 [CRITICAL — `gg check` passes and the binary SEGVs; the axis is the RECEIVER SHAPE, not the operation] `.clone()` on a `Callable` bound to a NAMED LOCAL segfaults; the byte-equivalent clone through a TEMP receiver is correct.**
  ```
  Callable[int(int)] h = (int x): x + 1
  Callable[int(int)] g = h.clone()        # -> SIGSEGV (signal 11)
  print(g(1))
  ```
  versus `Callable[int(int)] g = fns.get(0).unwrap().clone()` on the same value, which prints `2` correctly. `gg check` prints `OK: no semantic errors` for both.
  ⛔ **`.clone()` ON A CALLABLE IS A SUPPORTED OPERATION — DO NOT "FIX" THIS BY REJECTING IT.** `src/ir/lowering/builtins.rs:1109` registers `clone_fn: Some("gorget_closure_clone_to_owned")` (and `:1124` for `MutCallable`), and `tests/fixtures/security/attack_91_callable_clone_outlives_source.gg` (wired at `tests/security.rs`) exists precisely to pin the deep-clone path and is GREEN. A check-time rejection would regress a ratified feature and that fixture.
