  ```
  0 - INT64_MIN   ->  trap[T_Overflow]: integer overflow
  ```

  ## ⛔ THE ARGUMENT ABOVE LEANS ON ggdef AS AUTHORITY. **THAT IS THE WRONG ARGUMENT** (owner challenge, 2026-09-05)

  `AGENTS.md` is explicit: ***"ggdef IMPLEMENTS the definition, it is not the definition"*** (Core #13), and Core #8 says reference-grade is the bar, **not parity with a possibly-wrong reference**. I cited ggdef as settling the question. **It corroborates; it does not settle.** The conclusion survives — but on three grounds that never mention ggdef, and it is worth having them on the record in that order:

  **1. ⭐⭐ RUST gg CONTRADICTS ITSELF. Same overflow, same value, two answers by spelling:**
  ```
  int m = -9223372036854775807 - 1
  0 - m   ->  trap[T_Overflow]: integer overflow        (gg C)
  -m      ->  -9223372036854775808                      (gg C)   <- silent
  ```
  **That is not a lane divergence; it is one compiler disagreeing with itself.** Whichever answer is right, **both spellings must give it** — and that argument needs no oracle at all.

  **2. ⭐⭐ TRAPPING TAKES NOTHING AWAY, BECAUSE THE WRAP IS ALREADY SPELLABLE.** Measured: `0 -% m` → `-9223372036854775808`, **works today.** ⇒ **a user who wants wrapping negation already has a spelling**, and trapping `-m` routes them to it — **which is exactly what the `%` suffix family is FOR.** *(Unary `-%` does not parse and does not need to.)*

  **3. `D30` REJECTED DEFINED-WRAP ON THE GROUND *"silent corruption + inconsistent with int's trap"* — and `-m` is LITERALLY the inconsistency D30 named.** Plus the project's own severity ranking puts silent-wrong-output above a trap.

  **4.** *(Corroboration, not authority.)* ggdef traps, and does so **consistently with its own binary subtraction** — so the oracle is at least self-consistent on this axis, which is what makes it worth citing at all.

  ⚠ **THE STEELMAN FOR WRAP, ANSWERED:** the only real argument is the cost of a check on every negation. **Binary `-` already pays it**, negation is far rarer than subtraction, and *"perf never trades against safety"* is ratified design. **No case survives.**
