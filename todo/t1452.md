- **🆕🚨 [HIGH — A RECONCILIATION LINT WHOSE EXEMPTION REINTRODUCES THE HOLE IT EXISTS TO CLOSE. Found 2026-09-05 by the R50 orchestrator while reconciling the round-close battery against CI by hand.]**

  `round_close_battery_covers_ci_steps` was written because **three CI steps were once absent from the documented battery**, so a round could run everything AGENTS.md lists, go green, and leave CI red. Its doc comment now carries this exemption:

  > *"`--test security` satisfies CI's `--test security --release` under `GG_BACKEND=llvm` too, because the LLVM sweep bullet is what carries that."*

  ⛔ **THE LLVM SWEEP BULLET DOES NOT CARRY IT, AND THE SWEEP SCRIPT SAYS SO ITSELF.**
  - `scripts/run_integration.sh:66` → `exec cargo test --test integration "$@" -- --test-threads="$N"`. One target.
  - The same script's header comment, **lines 38-39**, lists what it does NOT cover: *"`cargo test --lib`, `--test lints`, **`--test security`**, `--test spec_conformance`, `-p ggdef`, and `python3 scripts/robustness_map.py`"*.
  - CI's step is a SEPARATE job entry — `.github/workflows/ci.yml:311-312`, *"Security tests (LLVM + ASan + UBSan)"*, `cargo test --test security --release -- --test-threads=1` with `env: GG_BACKEND: llvm`.

  **Measured consequence, this round:** R50's battery ran the plain `--test security` (rc 0) and the LLVM *integration* sweep (rc 0), passed this lint, and **never executed the LLVM-backend security suite at all**. `grep -oE '^Running.*security' /tmp/<llvm sweep log>` → no match.

  ⚠ **SIX-Q #2 — CAN THIS GUARD CATCH ITS OWN CLASS?** No. A guard that green-lights the class it was written to retire is worse than none, because the round-close checklist now cites it as evidence. The lint is not merely incomplete; it launders an absence into a pass.

  **Shape of the close (executor measures):** either (a) drop the exemption and add the LLVM security run to AGENTS.md's battery as its own bullet — the honest fix, since it IS a separate command with its own env — or (b) if an exemption is genuinely wanted, make it assert the covering command actually RUNS the target rather than asserting a bullet exists. **Whichever lands must FAIL against today's `tests/lints.rs`** (Core #6), and the AGENTS.md battery text must name the env (`GG_BACKEND=llvm`, `--release`), because a bullet that omits the env is not a runnable instruction.
