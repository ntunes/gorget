- **Dynamic dead-clone detection: count clones where NEITHER source nor copy is written afterward — the clone was provably unnecessary.** The dual of the dead-write warning (write-to-copy-nobody-reads ⟷ copy-nobody-writes). Mechanism (opt-in `--clones=waste` or extend `stats`; zero-cost off): register (site-id, src-buf, new-buf) per instrumented clone + per-buffer dirty bit; every MUTATING runtime entry point (push/set/insert/string-mut — the funnel CoW already forces mutations through) dirties its buffer; at free/exit, an un-dirtied pair = a WASTED clone for that site. Report `[waste-stats]` + per-site TSV → new columns in `clone_attribution.sh`: (site, reason, hits, wasted, waste%). **Per-site waste% = the sharpest charter meter** (100%-waste site = proven borrow candidate; grades even justified categories — a 99%-wasted consuming-position clone = a liveness gap). v0 CAVEAT: direct field stores bypass runtime entry points → v0 under-detects mutations, so waste verdicts are LEADS needing verification, not auto-fix truths; scout decides funnel-only (cheap) vs backend mark-dirty-on-store in instrumented mode (precise). Scalars/trivials OUT of v1. Serves: the SH bare-arg gap burn-down (ranked per-lane waste list), the per-reason budgets (a quality dimension), and the eventual static-warn subset (intraprocedurally-provable wasted clones → the warning family, per the wasteful-warns/unsound-rejects ruling).
