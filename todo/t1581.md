- **🆕🛡 [LOW — THE NAMED OMISSIONS OF `todo/t1360`'s FIX, recorded so they do not die with the brief that named them. Filed 2026-09-06 by R51 Track J's executor as the residue of its OWN change.]** `scripts/sanitize_sweep.sh` now emits column 5 of `verdicts.tsv` — `MEASURED`/`UNMEASURED`, read off ASan's `atexit=1` exit-stats marker — and the adjudicator refuses to call an unmeasured row fixed. The predicate is total over the axis by construction. **These four cells are nonetheless unwitnessed, and none of them is a reason to distrust the axis; they are the list of what a future round would have to build to claim it is exhaustively demonstrated.**

  **(a) THE MARKER CAN BE SPOOFED BY THE SUBJECT.** The producer greps the fixture's own stderr for `AddressSanitizer exit stats:`, so a fixture printing that string would read `MEASURED` without the check having run. Same pre-existing class as `classify_log`'s marker greps, which key on `ERROR: LeakSanitizer:` and friends in the same stream. **Zero corpus instances today** — regenerate with `grep -rl 'AddressSanitizer exit stats' tests/fixtures/`. A robust fix would read the marker from a channel the subject cannot write, e.g. `log_path` to a separate file.

  **(b) ONLY TWO OF THE NON-RUN TERMINATIONS ARE WITNESSED END-TO-END.** `BUILD_FAIL_BOTH` (via `tests/fixtures/sanitize_selftest/selftest_build_fail.gg`, asserted by `run_selftest` on every invocation) and `TIMEOUT` (R51 Track J's demonstration). `SKIP_COPY`, `NO_BINARY`, `RUNNER_FAIL`, `BUILD_FAIL_SANITIZE_ONLY`, `CRASH:*` and `ASAN_*` were driven at the ASan level only — the marker is absent in every one of those terminations, but no test drives them through `run_one`.

  **(c) THE UNANIMITY PATH IS UNEXERCISED.** `run_one` folds the per-rep marker with `sort -u` and demands every rep read `1`. No fixture is `MEASURED` on some reps and `UNMEASURED` on others, and the self-test's synthetic rows do not reach that fold. The `selftest_alternating_leak` shape (a marker file in the fixture's own working directory) is the obvious way to build one.

  **(d) `ICE` HAS NO CORPUS INSTANCE.** `scripts/verdict.py`'s `ICE` label is not `phase == "build"`-gated and fires on `rc == 101` plus a panic marker, so it is reachable at the sweep's call shape; the new axis handles it correctly by construction (an ICE'd fixture never reaches the at-exit check) but nothing in the tree exhibits one.

  **⊕ AND ONE THAT IS ALREADY FILED ELSEWHERE, NAMED HERE SO THE SET IS COMPLETE:** the stem-collision fail-open now reaches `$OUT/tmp/$stem.m`, a THIRD stem-keyed scratch file. See [[t0956]], whose stem→path re-key precondition is what closes it; no test drives two same-stem fixtures.
