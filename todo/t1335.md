- **🆕🧹 [MEDIUM — GUARD COVERAGE HOLE, no live defect; found 2026-09-05 by the R50 Track C2 output-review]** The LIR view-callee ratchet cannot see a producer selected through a typed axis, and the better the code gets the blinder it becomes.

  `tests/lints.rs::no_growth_in_lir_view_callee_rewrites` (BUDGET 41) counts **non-comment MENTIONS of view-producer callee names** — exact-quoted symbols and `RuntimeFn::` variant references — in `src/lir/**`. Its purpose is real: an LIR-level rewrite that swaps a callee for a view-returning one bypasses the four GIR materialize hooks, so a new mention must be reconciled against the producer enumeration before shipping.

  ⚠ **THE MECHANISM, NOT THE SYMPTOM.** `t0045` changed `src/lir/lower/insts.rs` to pick the String borrow primitive by reading `TypeMetadata::borrow_view_fn` instead of comparing against a runtime symbol's spelling. That is the Core #2 / devbook/24-rule-2 shape and it is correct. But it means the emit site **reaches `gorget_string_borrow_view` without ever spelling it in `src/lir/`** — so the ratchet's count did not move (41 → 41, verified: no slack was introduced and there is nothing to lower). ⇒ **the next type that gains a `borrow_view_fn: Some(...)` row in `src/ir/types.rs` becomes a new LIR view producer through that same site, and the ratchet stays green.** The guard's instrument counts spellings; the fix's correctness is precisely that there is no spelling.

  ⛔ **WHAT DISCRIMINATES THIS FROM THE FAMILY IT JOINS** — "a guard that cannot see its own class" (Six-Questions #2) has three members now, and they fail differently:
  * `str_view_producer_enumeration_is_closed` enumerates **SYMBOLS not SITES**, so a new emit site of an *already-blessed* symbol is invisible. Recorded in `tests/lints.rs::borrow_primitive_is_not_name_selected`'s doc block; not separately filed.
  * `VIEW_PRODUCERS_INTO_CONSUMERS` asserts a fixture **FILE EXISTS**, so it is inert with respect to any `src/` change — reverting a lowering cannot delete a file.
  * **THIS ONE** is different from both: the guard is a **counting ratchet**, its subject is present and correct, and it loses the producer because the producer stopped being *nameable*. Widening either of the other two does not reach it.

  **INTENDED:** the ratchet gains a second arm keyed on the TYPED AXIS rather than on spellings — the enumeration of `borrow_view_fn: Some(...)` rows in `src/ir/types.rs` (exactly one today, `String`, against 30 `None` protocol rows) reconciled against the producer table, so adding a row forces the same reconciliation that adding a spelling does. That is the `borrow_view_fn`-consumer enumeration the C2 gauntlet identified as closed and name-free: `grep -rn "borrow_view_fn" src/` returns the eligibility gate in `stmts/mod.rs`, `emit_lazy_loopcarried_borrow` in `context.rs`, and the `insts.rs` site.
