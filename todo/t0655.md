- **[HIGH — language semantics, ledger-grade] Narrow-type overflow is unenforced: `uint8 255 + 1` → 256 (no panic), `255 +% 1` → 256 (no wrap).** The book says "integer overflow always panics"; only 64-bit `int` does. Narrow types appear to be int64 in disguise — neither trapping nor wrapping at their declared width. Needs a D-decision (what IS uint8 arithmetic?) + conformance fixtures once ruled; check D26 (`+!`/ArithError) for the intended model first.
