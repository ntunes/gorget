- **🆕⚠ [MED — LANE GAP, deliberately narrower not broken: the self-host's D46 equality gate accepts every generic instantiation, so `Option[P]` / `Vector[P]` / `Pair[P]` with a non-`Equatable` `P` are refused by Rust gg and accepted by the self-host. Filed by R49 Track F-G, which shipped the narrow gate on purpose.]**
  - **WHAT SHIPPED.** `eq_blame_type_name` (`tests/fixtures/self_host_typechecker/typecheck.gg`) walks `RTRef` / `RTTuple` / `RTArray` / `RTSlice` structurally and gates `RTDefined` on `def_kind_is_declarable_type` plus the trait registry. It rejects the whole cross-lane seed set (`spectests/run/reject_eq_*.gg`, five seeds, all MATCH on the self-host lane) including the qualified-variant shape.
  - **WHAT IT CANNOT DO, AND WHY.** Rust's gate splits `ResolvedType::Generic` on a TYPED flag, `DefInfo.has_intrinsic_equality`, seeded ONCE at registration from `builtin_has_intrinsic_equality` (`src/semantic/scope.rs`) — the same one-allowed-registration-name-match precedent as `DerefWrapperKind::for_builtin_name`. It is what lets `Vector[P]` recurse into `P` while `Pair[P]` demands its own derive, even though both arrive on the same variant. The self-host `DefInfo` has no such field, so its gate ACCEPTS every `RTGeneric` — the safe direction, since it can never over-reject working code, but it diverges from Rust on those cells.
  - **FIX SHAPE (mirrors Rust exactly).** Add `bool has_intrinsic_equality` to `DefInfo` (`tests/fixtures/self_host_typechecker/scope.gg` — 3 construction sites, plus `define_replace_or_fail`, which builds a FRESH `DefInfo` when a real definition displaces an import placeholder and must carry the flag across). Seed it in `tests/fixtures/self_host_typechecker/resolve.gg` at the two registration points Rust seeds: the builtin-collection `col_names` loop, and the prelude `Option`/`Result` enums. Then add the `RTGeneric` arm to `eq_blame_type_name`: flag set ⇒ recurse into the type arguments, flag clear ⇒ require an `Equatable` impl. ⚠ `self_host_check/` and `self_host_lowerer/` SYMLINK the typechecker's copies of all three files — edit the typechecker copy only; `self_host_resolver/` has its own `scope.gg` + `resolve.gg` and no `typecheck.gg`, so it needs nothing.
  - **INTENDED:** all four lanes agree on `Option[P] == Option[P]`, `Vector[P] == Vector[P]` and `Pair[P] == Pair[P]` for a non-`Equatable` `P`. The Rust-lane cells are pinned today by `d46_eq_option_element_not_equatable_rejects`, `d46_eq_vector_element_not_equatable_rejects` and `d46_eq_user_generic_struct_rejects` (`tests/integration.rs`); this item adds the self-host halves and promotes them to cross-lane seeds.
