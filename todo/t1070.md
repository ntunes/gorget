- **🆕🧹 [LOW — EXCESS CLONE, safe not unsound; found R49 Track L pass-4 review, measured 2026-09-04] A closure capture whose ONLY occurrence is inside an f-string interpolation cannot be moved even when the source is dead, because the interpolation carries no span.**
  - **MECHANISM.** R49 Track L gave `CaptureInfo` the capture's OCCURRENCE span so the shared consuming-position helpers can ask `is_last_use_at` a question keyed on a real position (the enclosing closure span always answers a conservative `false`). `StringSegment::Interpolation(String, Option<String>)` (`src/lexer/token.rs`) **carries no span**, and `FreeVarCollector` recovers the captured identifier by string-splitting the interpolation TEXT (`src/ir/lowering/closures.rs`), so there is no occurrence span to record. The fallback is the enclosing string literal's span — conservative-false — and the capture clones.
  - **⭐ AIRTIGHT A/B, one program, one edit.** `String prefix = mk("pre","fix"); Callable[String()] f = (): mk(prefix, "!")` → `string_clone = 0`, `total_allocs = 2` (the optimum; the source is dead, the capture moves). The SAME program with the body respelled `(): f"{prefix}!"` → `string_clone = 1`, `total_allocs = 4`. Nothing else differs.
  - **⚠ IT IS SAFE.** The conservative answer is a clone, which is always sound; the cost is one extra materialisation per such capture. This is a charter question (*implicit clones must be as good as the best hand-written code*), not a soundness one.
  - **⚠ NAME THE CELL THIS DOES NOT CLOSE (Core #12).** `tests/fixtures/stress_alloc_closures.gg` line 28 — `f"{prefix}-{n}"` — IS this cell, and it is the fixture whose 500 clones were offered as the evidence that closure captures over-clone. Those 500 are UNCHANGED by Track L and will stay until an interpolation carries a span. The live guard `closure_capture_capture_cost_axis` (`tests/integration.rs`) pins the two NON-f-string cells with exact equality and says in its own header that it does not reach this one.
  - **THE FIX** is to give `StringSegment::Interpolation` a span at the lexer and thread it to `FreeVarCollector`'s f-string arm — after which the same occurrence-span path already in place answers correctly, with no change to the capture rule.
  - **INTENDED:** the f-string spelling costs what the call spelling costs — `string_clone = 0` when the captured source is dead.
