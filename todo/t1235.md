- **🆕🧹 [LOW — the RESIDUAL of the class R49 Track A2-α retired, and the reason A2-α's claim is scoped rather than absolute. Found 2026-09-04 by A2-α's output-review] The five `IndirectCallee::Named` arms still cross the layer boundary as a name, and `__Closure_N__call` is still minted into the namespace user code writes into.**
  - **WHAT A2-α DID AND DID NOT DO.** It retired conventions 2 and 3 — `__callable_<slot>` and `__gorget_closure_call_<slot>` — by carrying the callee's identity on `Instruction::CallIndirect`. Four of the nine indirect-dispatch arms lost their manufactured name entirely. **The other five still pass one**, and for three of them that is correct and permanent: a trait-object vtable slot and a `Constant::FuncRef` name a callee that genuinely exists, and at the C-emit boundary the symbol IS the contract (devbook/24's stated exception). ⚠ **`__Closure_N__call` is different: it is MINTED**, `format!("__Closure_{id}__call")` at `closures.rs`, into the same flat, module-global, string-keyed namespace user functions live in.
  - **MEASURED, 2026-09-04** — `int __Closure_0__call(int a): return a + 1` beside any closure call:
    | stage | result |
    |---|---|
    | `gg check` | **rc 0 — accepted** |
    | `gg build` | **rc 101**, `GIR validation errors: module: duplicate function name @__Closure_0__call` |
    | pre-A2-α compiler | **identical** |
  - ⭐ **WHY THIS IS LOW AND NOT THE HIGH ITS SIBLING WAS, and the distinction is the whole point.** The retired conventions produced **silent wrong output** — a heap-derived number with rc 0 and a clean `gg check` — because the manufactured name *resolved to the user's function* and dispatch continued. This one is caught by the GIR validator's duplicate-name check and stops the build. **Loud is not fixed**, but it is not a soundness hole: no binary is produced, so nothing can be wrong at run time. It is a missing REJECTION at check (Core #10: `gg check` accepts a program the compiler cannot lower) plus a Layering-rule-2 residual.
  - ⚠ **DO NOT "FIX" IT BY WIDENING A NAME TEST.** The reference-grade shape is the one A2-α used: the identity belongs on the instruction. A closure call thunk is a real emitted function, so the honest question is whether the MINT should be collision-proof (a name the surface language cannot spell, or a module-scoped symbol table) rather than whether the CALL should stop naming it. The cheap defensible interim is a check-time rejection with a diagnostic that names the collision, instead of a GIR-validator panic with no source span.
  - **NOT COVERED BY A2-α'S NET.** Its 16 `closure_identity/` cells all exercise the two retired prefixes; there is no cell for any `Named` arm. A fix here owes one, RED-verified.
