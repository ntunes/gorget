- **🆕📋 [LOW — SUBSET GAP, filed so a Core #9 ABSTENTION is a citation rather than a silent omission; from R49 Track S-a2] ggdef models the single-owner carve-out for `Callable` only, so the sub-place reject lands there for one member of a family of seven.**
  - **WHAT LANDED.** R49 Track S-a2 made the by-design single-owner carve-out reject at FIELD and TUPLE-ELEMENT places on all three lanes. ggdef carries it (`reject_if_single_owner_callable_init`'s sub-place pre-block, pinned by the `d53_callable_subplace_*` rows), including both tuple spellings and the `v[0].f` keying cell.
  - **WHAT DOES NOT.** Production's predicate is `needs_explicit_move` (`src/semantic/safety/type_utils.rs`), which covers `Function | CallableTrait | MutCallableTrait | ConsumeCallableTrait | BoxedCallable | Owned` plus generic `Box | Task | TaskGroup | Guard | Mutex | RWLock`. **None of the non-callable members exist in ggdef's `Ty`** — regenerate by enumerating the vocabulary itself: `sed -n '/^enum Ty {/,/^}/p' spec/ggdef/src/elaborate/mod.rs | grep -oE '^    [A-Z][A-Za-z]*'` → `Prim Str Vector Dict Set Tuple Option Result Named Callable Unknown`, and not one of the family is among them. ⚠ **Do NOT regenerate this by grepping the file for the type NAMES** (`grep -rn 'Mutex\|RWLock\|Box' … | grep -c 'Ty::'`): every hit is Rust's own `Box::new` BUILDING the `Ty` tree, so it returns a healthy non-zero count and invites the exact opposite conclusion. So `Box[Payload] taken = h.b`, which production now rejects (`single_owner_subplace/box_field_bind_reject.gg`), has no ggdef surface at all: it is not accepted-when-it-should-reject, it is unwritable.
  - ⚠ **WHY THIS IS FILED RATHER THAN SHRUGGED OFF.** The abstention is currently recorded only in a fixture-header line and a test comment. `todo/t0875`'s lesson is that a fact living only in prose beside the thing it describes rots the first time either moves; and Core #9's ABSTAIN branch is explicitly *"with citation"*, which requires something to cite.   - **WHAT WOULD CLOSE IT.** Either (a) ggdef grows a `Ty` for one non-callable carve-out member — `Box[T]` is the cheapest, it needs no runtime, and it would let the family-reach claim be pinned rather than argued; or (b) a ruling that ggdef's phase-0 subset deliberately excludes the family, recorded in the RFC, at which point this item closes as WONTFIX with the exclusion written down.
