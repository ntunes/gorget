- **🆕🧹 [MED — LAYERING RULE 3, a second source of truth on the ownership axis, with NO measured live defect today; found R49 Track L (brief item S5), left unfixed and filed because the harm is structural rather than observable] The SECOND closure-env `StructInit` producer asserts the ownership its sibling now derives.**
  - **THE TWO PRODUCERS.** A `__Closure_N` `StructInit` is minted at exactly two sites — established both statically (`Instruction::StructInit` has one production constructor, `FunctionBuilder::struct_init`) and dynamically (backtrace capture on `type_name.starts_with("__Closure_")` over 1057 closure-bearing fixtures → 750 emissions: `lower_closure` 744, `build_spawn_wrapper` 6, nothing else). ⚠ **THE PATH IS `src/ir/lowering/exprs/spawn.rs`** — the `exprs/` segment is easy to drop and a grep without it finds nothing.
  - **THE ASYMMETRY.** `lower_closure` now routes its `StructInit` through the shared consuming-position sequence (`ensure_owned_at_boundary` → `clone_multi_use_resource_args` → `move_zero_consumed_args`), so what each capture operand owns is DERIVED at the boundary. `build_spawn_wrapper` instead writes `LocalOwnership::Owned` directly onto every capture param, in a loop whose own comment names the diagnostic it is silencing: *"Without this tagging, params start as Untracked, and the validator fires `StructInit … untracked source consumed` at the struct_init below."* That is an assertion standing in for a decision, on the same axis, at the same instruction kind.
  - **⚠ WHY IT MATTERS MORE NOW THAN IT DID.** The `is_closure_env` consume-site carve-out that made the whole question invisible is gone, and the env `TypeDef` the wrapper reuses now carries a TRUTHFUL `drop_strategy` / `copy_semantics` computed from its fields. The hand-tag is therefore no longer a shrug at an unvalidated site — it is the one remaining place where a closure env's field ownership is asserted rather than established, and the assertion is what keeps the now-live validator quiet there.
  - ⛔ **RETRACTED 2026-09-04 — "MEASURED NO LIVE HARM" WAS FALSE, AND THE INSTRUMENT IS THE LESSON.** This bullet used to read *"measured no live harm … `--test integration spawn` is 36/0 on C and LLVM"*. **A stdout assertion cannot observe a leak.** That is SIX Q#2 — a green cell green for a reason unrelated to what it was thought to test — sitting inside a filed item as its reason not to block.
