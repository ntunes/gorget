- **🆕🐛 [MED — module-loader leniency, found by the CoW-1A output-review probe 2026-07-17] Importing ANY name from a module silently exposes ALL of that module's names.** `lower_expr.gg` called `for_iterable_mode` (defined in `lower_loops.gg`) WITHOUT it appearing in the `from lower_loops import …` list, and the build succeeded — the loader resolves unimported names once any name from the module is imported. Accepts what the import system implies should be rejected (an unimported-name use should be `E_UndefinedName`); it also lets import lists silently rot. Fix in the loader/resolver's import-visibility check + a negative fixture; sweep existing `.gg` sources for other unimported-name uses that the leniency currently masks (each is a latent build break). The 1A remediation added the missing import explicitly.
