- **🆕🚨 [HIGH — SELF-HOST SILENT WRONG OUTPUT, not a crash: a static TRAIT method returning a `String` returns its LENGTH; found 2026-08-31 by the R48 Track C output review, root-caused and minimised by the executor] The self-host prints `10` where Rust gg and ggdef print `helloworld` — and `10 == len("helloworld")`.** It compiles, links and exits 0, which is why nothing caught it: only a value comparison can see this class.
- **THE LENGTH HYPOTHESIS IS OVER-DETERMINED, and both discriminators are measured against a driver built from the PRE-fix compiler:**

  | shape | self-host prints | Rust gg |
  |---|---|---|
  | `equip Cell with Maker: String make(): return "abcdefg"` | **`7`** | `abcdefg` |
  | `equip Cell with Maker: String make(): return "helloworld"` | **`10`** | `helloworld` |
  | `int tag()` on the SAME equip-with-trait block | `42` ✅ | `42` |
  | the identical `String make()` on a PLAIN `equip Cell:` (no `with Maker`) | `abcdefg` ✅ | `abcdefg` |

  ⇒ It is **String-return-specific** (the `int` sibling on the same block is correct) and it is **the static TRAIT-method path specifically** (the same method on a non-trait `equip` is correct). Two axes, each pinned by a control that is green.
- **PRE-EXISTING.** An 11-line program with no view, no realloc and no CoW machinery reproduces it. It surfaced now only because R48 Track C's path-axis net was the first thing in the corpus to put a static trait method on the self-host lane.
- **Where to look:** the self-host analogue of Rust's `lower_static_trait_method` — the `fn_sigs` / return-type registration for a trait-provided STATIC method under `lower.gg`'s trait-default and equip-with-trait emission. The plain-`equip` path registers the return type correctly, so the two paths disagree on one axis; that disagreement is the bug (Layering rule 3 — one source of truth per axis).
