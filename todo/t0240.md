- **Self-host snag #4: scalar slot for struct value via `EFieldAccess`-as-method return-type inference fallback.** `String x = path.byte_slice(...)` / `__gg_CsvTable t = parse_csv(...)`: `var_type` in `lower.gg`'s SVarDecl inherits the init expr's inferred type, which falls through to `I64_TYPE` when the call routes through `EFieldAccess`-as-method (~:2035) or `infer_method_return_type` doesn't know the return type → slot typed `int64_t`, downstream reads get zeros (manifests as `OutputMismatch`). Fix: (a) prefer the DECLARED type when concrete and inferred defaulted to I64; (b) OR fix the writer — the `EFieldAccess`-as-method path at `~:2035` returns `UNIT_TYPE` blindly instead of `infer_method_return_type`/`fn_sigs`. Affects `csv_delimiters.gg` + a tail binding `String last = path.byte_slice(...)`.
