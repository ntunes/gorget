- **📐 [MED — Layering rule 3 (one source of truth per axis): the Gorget-type → C-name-fragment axis has TWO parallel primitive tables and a wrong-answer default at the end of one of them; filed 2026-09-04 by R49 Track M1, which consumed the accessor rather than collapsing the tables] `c_type_name_for_id` and `mangle_type_for_name` are two hand-maintained spellings of the same mapping.** `LoweringContext::c_type_name_for_id` (`src/ir/lowering/context.rs:4788`) matches on a `TypeId` and lists 11 primitive arms; `mangle_type_for_name` (`src/ir/lowering/types.rs:1320`) matches on an AST `&Type` and lists 14 (it also has `cstr` and folds the width aliases). **Neither reads the other.** ⚠ **AND EACH ENDS IN A DEFAULT THAT INVENTS AN ANSWER:** `c_type_name_for_id`'s `_ =>` falls to `type_name_for_id(..).unwrap_or("int64_t")` (`context.rs:4803`), and `mangle_type_for_name`'s outer `match ty` ends `_ => "unknown"` — so a type neither table knows gets a *plausible* C name rather than a refusal. ⊕ **THE CLASS IS WIDER THAN THE TWO TABLES:** `grep -rn 'unwrap_or("int64_t")' src/` returns **30** sites tree-wide (it was 32 before R49 M1 retired two). Each is a place where an unresolved element type silently becomes a 64-bit integer — the exact mechanism behind `t0680`, whose primitive face is closed but whose CLASS is not. ⊕ **DO NOT "FIX" THIS BY ADDING A THIRD DERIVATION.** An R49 M1 brief erratum ordered exactly that and was struck by measurement: `mangle_type_for_name` takes an AST `&Type` and there is no `innerTypeId → name` direction through it at all, so a mint holding a `TypeId` cannot consume it. `c_type_name_for_id` IS the single accessor for the `TypeId` direction (21 call sites, including both live `Box` mints and the `Shared` / `Weak` arms of `lower_struct_literal`); the work is to give the two tables ONE seeded source, not to route a third caller around them. **THE WORK:** (a) one primitive roster, read by both, with the AST-side and TypeId-side entry points as thin adapters; (b) turn both terminal defaults into an explicit refusal or a typed `Option` the caller must handle (Core #10, lower-or-reject), starting with `c_type_name_for_id` — R49 M1 measured its residue arm firing **0 times** across all 70 `Box`-mentioning fixtures and **0 times** building `self_host_lowerer/driver.gg`, the largest Gorget program in the tree, so the change has no live consumer to break; (c) burn the 30 `unwrap_or("int64_t")` sites down with a `tests/lints.rs` ratchet in both directions. No repro: this is a layering/robustness item, not a live miscompile — its known miscompile face (`t0680`) is closed and has its own graduated fixture.
