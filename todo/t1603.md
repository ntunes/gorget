- **🆕💥 [HIGH — AN ICE FROM ORDINARY SAFE SYNTAX. Found 2026-09-06 by R51 Track K's brief-review pass 2, incidentally, while probing an unrelated subject.]**

  ```gorget
  struct W[T]:
      T source
      int n
  # ...
  auto w = W(d, 0)        # generic args INFERRED, not spelled
  ```

  ⇒ `GIR validation errors: function @main, bb0: reference to undefined type 'W'`, then **`panicked at src/ir/lowering/mod.rs:1734:13`, rc 101.**

  **The discriminator:** spelling the generic args explicitly (`W[Ref[Dict[String,int]]](d, 0)`) compiles and runs. **Only the INFERRED-args form ICEs**, so the defect is in the path that materializes a monomorphized struct type from an inferred instantiation, not in generic structs as such.

  ## WHAT DISCRIMINATES IT FROM `[[t0933]]` — the family is "GIR validation reports an undefined type, then the lowerer panics"

  | item | mechanism | trigger |
  |---|---|---|
  | `[[t0933]]` | registering `Vector[Option[U]]`'s protocol methods **does not register the `VectorIter__…`/`VectorDrain__…` ADAPTER INSTANCES** those methods reference | a builtin container's adapter chain |
  | **this item** | a **USER generic struct** whose **generic args are INFERRED at a constructor call** is never registered at all | `auto w = W(...)` with no explicit args |

  **Same symptom and same panic site; different producer.** `t0933` is about adapters the registrar forgot to follow; this is about an instantiation the registrar never saw. **Do not close either by fixing the other** — check both triggers.

  ⚠ **AND THE PANIC IS THE SECOND DEFECT.** GIR validation *detected* the problem and produced a diagnostic; the lowerer then panicked anyway instead of surfacing it. **A validation error that reaches a `panic!` is a Core #10 lower-or-reject breach in its own right** — the user sees an ICE where a clean rejection already existed.

  **INTENDED:** an inferred-generic-args constructor registers its monomorphized type exactly as the explicit form does; failing that, the existing GIR validation error is *surfaced as a diagnostic*, never as a panic.
