- **🆕🚨💥 [CRITICAL — MEMORY-UNSAFE FROM ORDINARY SAFE SYNTAX, both backends, `gg check` clean; found 2026-09-05 by R50 Track H's scout while measuring an unrelated leak]** `Vector[String].fill(n, x)` double-frees.

  **Measured at PRISTINE HEAD** (independent of Track H's fix):
  ```gorget
  Vector[String] v
  v.fill(3, mk("ab", "cd"))
  # -> AddressSanitizer: attempting double-free (gorget_array_free -> gorget_string_free)
  ```

  ⭐ **MECHANISM — a missing per-slot clone, not a drop-tracking error.** `gorget_array_fill`
  (`grep -n "gorget_array_fill" -A 14 src/backend/c/runtime/runtime_array.c`) **memcpys ONE source into N
  slots** and never calls the materialize hook, so all N slots alias one heap payload and the array's free
  releases it N times.

  ⛔⛔ **CORRECTION 2026-09-05 (orchestrator, measured): THE SIBLING CLASS I FILED DOES NOT EXIST — AND THE REAL
  DISCRIMINATOR IS SHARPER.** The filing said `gorget_array_set` / `insert` / `gorget_shared_array_set` share the
  missing hook and were "the same shape, unmeasured". **Measured at pristine HEAD under ASan: `.set(0, mk(..))`
  → CLEAN; `.insert(0, mk(..))` → CLEAN; `.push(mk(..))` → CLEAN.**
  ⇒ ⭐ **THE DISCRIMINATOR IS NOT *"lacks the materialize hook"* — IT IS *"WRITES ONE SOURCE INTO MORE THAN ONE
  SLOT"*.** `set` and `insert` place **one value in one slot**, so nothing aliases and **their absence from the
  hook list is CORRECT, not a gap.** `fill` is the only writer that DUPLICATES. ⇒ **the class has ONE member**,
  and the enumeration that made it look like four was reasoning from **hook presence** instead of from
  **duplication** — *a property of the WRITER, not of the WRITE.*
  ⚠ **`gorget_shared_array_set` remains genuinely unmeasured; judge it by the duplication test, not by the
  hook.** **Regenerate the hook sites with** `grep -n "elem_materialize(" src/backend/c/runtime/runtime_array.c`
  **→ 2, both in the push path.**

  ⭐ **WHY IT WAS NEVER SEEN: every existing `.fill` fixture uses POD elements** (`bool`), which have no payload
  to alias. **That is a fixture set that samples one value of a typed axis (Core #12) — the droppable-element
  cell was never covered.**

  ⛔ **A DOCUMENTED INVARIANT WITH NO GUARD (Core #14), AND IT IS SIX-Q #4.**
  `docs/devbook/11-copy-on-write.md` asserts a **TOTAL** contract — *"Every consuming runtime function
  (`gorget_array_push`, `gorget_map_put`, …) obeys the same three-step shape: memcpy the caller's bytes into the
  slot, then call the materialize hook, then return"* (regenerate: `grep -n "obeys the same three-step shape"
  docs/devbook/11-copy-on-write.md`). **`fill` obeys none of it, and nothing enforces the sentence.** ⇒ **the
  case has NO SUBJECT in that sentence, so no widening of the rule reaches it — it needs a second clause AND an
  executable guard.**
