- **[LOW — honest coverage note, from D21 `gg sim` deletion 2026-07-24] No exact live successor for sim's type-agnostic `UninitializedRead` slot-liveness check** (was `src/sim/dispatch.rs:815+`, now deleted). `--sanitize` wires ASan+UBSan (`-fsanitize=address,undefined`) but NOT MemorySanitizer, and UBSan only validates `bool`/`enum` load-validity, not a generic uninitialized read of an arbitrary-typed local. Plausibly unreachable from valid Gorget source (type-first decls mandate initializers, so an uninit read would require a lowering bug), and sim only ever checked its OWN GIR execution, never the real backend — so no user-facing guarantee was lost by the deletion. If a future lowering bug ever produces an uninit read, the successor is wiring MSan into `--sanitize` or a static check, NOT resurrecting the interpreter.
