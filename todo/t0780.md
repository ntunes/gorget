- **🆕🐛 [HIGH — UNDEFINED BEHAVIOUR in emitted C, measured 2026-08-29 at `f3feea79` on a corpus fixture; C lane] `sort()` / `sorted()` / `unique()` on an EMPTY collection pass `NULL` to `qsort`, which is declared `nonnull`.** UBSan on `tests/fixtures/test_vector_sort_methods.gg` (its `# === 5. sort() on empty vector ===` case) prints `runtime error: null pointer passed as argument 1, which is declared to never be null` — twice, from the emitted helpers `gorget_array_sort_int` and `gorget_array_unique_int`. An empty `GorgetArray` has `data == NULL` and `len == 0`, and `qsort(NULL, 0, …)` is UB by the C standard even at length zero, so this is not "benign because nothing is read" (Core #8: *benign because it is UB anyway* is a red flag, never a pass). **Minimal repro** (three findings, one program):
  ```
  from std.collections import Vector
  void main():
      Vector[int] v = Vector[int]()
      v.sort()
      print(v.len())
      Vector[int] u = v.unique()
      print(u.len())
      Vector[int] s = v.sorted()
      print(s.len())
  ```
