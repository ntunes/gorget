- **🆕🛡 [HIGH -- A GUARD THAT CANNOT CATCH ITS OWN CLASS (SIX-QUESTIONS #2): THE LEAK SWEEP TREATS `did not run` AS `did not leak`; found 2026-09-05 by the R50 CoW design scout]** The sweep tells you to delete allowlist rows for fixtures it never measured.

  **Regenerate the mechanism** (Core #15(a)):

  ```bash
  grep -n 'seen\[\$1\]=1' scripts/sanitize_sweep.sh          # set only on a LEAK verdict
  grep -n 'for (s in allow) if (!(s in seen))' scripts/sanitize_sweep.sh
  grep -n 'sort -u > "\$OUT/covered"' scripts/sanitize_sweep.sh
  ```

  `seen` is set only where the verdict field matches `LEAK`. **Every non-run outcome therefore looks
  exactly like a clean run**: `SKIP_COPY`, `NO_BINARY`, `RUNNER_FAIL`, `BUILD_FAIL_SANITIZE_ONLY`,
  `BUILD_FAIL_BOTH`. The row lands in `fixed_leak` and the sweep prints
  `✅ no longer leaking — … DELETE them`.

  **The advisory's existing hedge does not cover this.** It warns that a *renamed stack frame*
  vanishes like a fixed leak and says to check for a paired ❌. A fixture that never built has no
  paired ❌ to find, so the hedge reads as confirmation.

  **⛔ It is not only advisory.** The same blind set feeds `retire_due`, and `retire_due` prints
  under `⛔ CITED ROW(S) WHOSE DEFECT IS FIXED — DELETE OR TIGHTEN THEM`. So **a build break can
  force the deletion of an allowlist row that documents a live, cited defect** -- the gate converts
  its own plumbing failure into an instruction to discard evidence. That is the failure direction
  that matters: a leak-admitting row is a *record*, and this erases records on infrastructure noise.

  **The fix is one intersection, and the operand already exists.** `$OUT/covered` is computed
  immediately before `adjudicate_leaks` is called and is defined as exactly "produced a RUN verdict
  at all". `fixed_leak` must be intersected with it; rows in `allow` that are *not* covered belong
  in a third bucket -- **UNMEASURED** -- which is neither "fixed" nor "leaking" and must never
  produce delete advice.

  **Core #6 / SIX-QUESTIONS #2 -- verify the verifier.** The guard for this fix is a deliberate
  break: force one allowlisted fixture to `BUILD_FAIL` and assert the sweep reports it as
  UNMEASURED and does **not** name it in `fixed_leak` or `retire_due`. ⚠ **Anchor that break BY
  LINE, never by substring** (Core #13) -- the fixture-copy site has identically-spelled siblings.
