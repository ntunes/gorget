- **🆕 [MED — SIX-Q #4: A CASE WITH NO SUBJECT. Found 2026-09-05 by R50 Track A2's brief-review pass 4; untested by anything in the corpus.]**

  `rewrite.rs` early-returns on a **14-name `COLLECTION_TYPES` list BEFORE** the `DefKind` gate that turns a constructor call into an `Expr::StructLiteral`. ⇒ **a user newtype whose name collides with one of those names — `newtype Channel(String)`, `newtype Arena(int)` — is silently NOT rewritten and keeps the un-rewritten path.**

  ⛔⛔ **NO WIDENING OF THE `DefKind` GATE REACHES IT.** The gate is never consulted, because the early-return already fired. **That is what makes it a case with no subject rather than a gap in the rule** — and it is precisely why R50 Track A2's fix, which is exactly that gate, leaves this cell untouched.

  ⚠ **UNTESTED BY ANYTHING.** No corpus fixture declares a newtype whose name collides with a collection name, so the cell has never been exercised in either state. **The severity is therefore UNMEASURED, not low** — it inherits whatever the un-rewritten path does, which for a non-scalar payload is silent wrong output on C.

  **INTENDED:** a user newtype is rewritten regardless of whether its name collides with a builtin collection name — or the collision is rejected at declaration, which is a separate accept/reject change.
