- **🔧 [LOW — A GUARD WHOSE SUBJECT IS THE DECLARATION, NOT THE VALUE (SIX-Q #2). Filed 2026-09-09 by the output review of the `lint.name_prefix.sites` fix.]**

  `figures_db_name_prefix_regen_alternation_matches_the_lint` asserts that the prefix alternation embedded in `lint.name_prefix.sites.regen` is identical to `MANGLED_PREFIXES.join("|")`. That closes the drift hole it was written for — a prefix with no `src/` site moves no number, so `figures.py check` cannot see it. Regenerate the size of that hole:

  ```
  for p in $(grep -oP 'starts_with\\\("\(\K[^)]+' scripts/figures.db | tr '|' ' '); do
    printf '%s %s\n' "$(grep -rhoE "starts_with\(\"${p}__\"\)" --include='*.rs' src | wc -l)" "$p"
  done | grep -c '^0 '
  ```

  ⚠ **BUT ITS SUBJECT IS THE TEXT, NOT THE MEASUREMENT.** It anchors on `starts_with\("(` … `)__"\)` and compares what sits between them. A regen rewritten to keep that substring while grepping a different target passes — including the exact shape the row was repaired to escape, a regen that reads `NAME_PREFIX_BUDGET` and so asserts a literal equals itself. The lint's own panic message names that shape as forbidden, which makes it an invariant-asserting comment with no guard behind it (Core #14).

  Nothing else covers it: `figures.py check` compares `measured == value` and is satisfied by any command printing 204, and `figures_db_mirrors_agree` only relates `value` to the in-tree constant.

  **INTENDED:** decide whether the regen's *shape* is worth pinning at all before pinning it. The honest options, in preference order:
  1. **Leave it.** The failure needs a deliberate rewrite past a panic message that spells out the prohibition; the drift this guard was built for is accidental, which is the class worth automating.
  2. Assert the regen also contains the census target (`--include='*.rs' src`), which is cheap but is one more piece of text a rewrite can satisfy while lying.
  3. Give `figures.py` a typed `regen_kind` so "this row re-runs a census" is a declared field rather than a substring — the only shape that is not another costume, and the only one that pays for itself across all 40 rows.

  ⛔ **DO NOT widen the existing lint to option 2 without settling option 3 first** — a second text check makes the guard look stronger while catching nothing new.
