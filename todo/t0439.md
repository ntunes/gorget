- **🆕 [D23/T3a follow-up, filed 2026-07-10, MEDIUM-design] General must-use on `Result`.** D23/T3a pins ONLY that an unhandled `throws` call in a CONSUME position rejects (`E_UnhandledThrows`). It does NOT catch a `Result` VALUE that is captured then ignored — `auto r = throws_call()` bound but never matched, or a `Result`-returning fn's value discarded even inside a `throws` fn. Whether Gorget wants a general `#[must_use]`-style must-use-on-`Result` (warn or error on a dropped `Result`) is a separate language-design question — deliberately OUT of D23 scope (owner Q4 ruling). Design + owner-decide before implementing; pairs with the error-model residuals.
