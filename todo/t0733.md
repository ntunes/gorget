- **[MED — AN UNIMPLEMENTED FEATURE IS DOCUMENTED AS IF IT EXISTS: `RawPtr[T]` has a numbered design section and a worked book example, and the compiler has never heard of it. Found 2026-08-29 by R47 Track C while trying to build a user-code UAF; disposition sharpened by its output review.]**
  - **VERIFIED AT HEAD.** `grep -rln 'RawPtr' src/ tests/ spec/` → **nothing**. Same for `ConstRawPtr`. It is documented in **two** files: `docs/book/21-interop.md` (6 occurrences, including a `## Raw Pointers` section with a worked `unsafe:` example) and `docs/language-design.md` (6 occurrences under **`### 11.3 Raw Pointers`** — a numbered design section, not marked planned or aspirational). `docs/language-reference.md` has zero, so the *spec* never claimed it; the book and the design doc do.
  - **THE BOOK'S OWN EXAMPLE DOES NOT COMPILE**, and fails twice over:
    ```
    $ gg check <the docs' unsafe example>
    error[E_UndefinedName]: undefined name `null`
    error[E_UndefinedName]: undefined name `RawPtr`
    ```
    `null` is undefined as well, so a reader following `docs/book/21-interop.md` types the snippet and gets two resolution errors from a *learn-the-language* chapter. That is the sharper half of this item: the design doc misleads a contributor, the book misleads a beginner.
  - **⚠ FRAME IT AS "IMPLEMENT OR MARK PLANNED", NOT "THE DOCS ARE WRONG".** Per this project's own rule the docs state INTENDED behaviour and the code shows what IS, so a doc-vs-code conflict here is not automatically resolved in the code's favour. Two coherent dispositions and they are not interchangeable: (a) **implement** `RawPtr[T]`/`ConstRawPtr[T]` (+ `null`) as the FFI escape hatch both documents describe, or (b) **mark both sections planned** and remove the worked example from the book until it exists. Which one is an owner call — it is a language-surface decision, not a typo.
  - **SCOPE NOTE.** `docs/language-design.md:2002` also uses `RawPtr[void]` to illustrate a *Sendable* rule ("RawPtr is NOT Sendable"), so the type is load-bearing in prose beyond its own section; whichever disposition is chosen has to reach that site too.
