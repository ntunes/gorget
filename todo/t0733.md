- **🆕🐛 [MED — a VIEW-VS-OWNED axis divergence, i.e. Layering rule 1's explicitly named invariant, on a path the bootstrap uses heavily; R47 Track D1 scoped this as MEASUREMENT-GATED and the gate did NOT clear, so it is filed with the measurement obtained rather than landed] The self-host types every String-returning builtin as the `str` VIEW; seven of them ALLOCATE.**

  `tests/fixtures/self_host_typechecker/infer.gg`'s String-returning ladder arm returns `types.string_id` for all nine names it admits. Rust gg splits exactly these names by ownership (`src/semantic/typecheck.rs`, the `"str" | "String"` arm — verified at HEAD 2026-08-29):

  | Rust answer | names |
  |---|---|
  | `string_id` — a `Str` VIEW, no allocation | `trim`, `strip`, `lstrip`, `rstrip`, `trim_left`, `trim_right`, `removeprefix`, `removesuffix`, `byte_slice`, `substring`, `slice` |
  | `owned_string_id` — an allocated `GorgetString` | `to_upper`, `to_lower`, `upper`, `lower`, `clone`, `replace`, `repeat`, `join`, `pad_left`, `pad_right`, `debug`, `display` |

  Of the nine the self-host arm admits, **`trim` and `strip` are correct and the other seven** — `to_lower`, `to_upper`, `lower`, `upper`, `replace`, `join`, `repeat` — **are typed as views when they allocate.**

  - **⚠ DO NOT FLIP THESE BLIND, and that is why it is filed.** Changing the ownership axis changes DROP-TRACKING, and the failure mode is a leak or a double-free rather than a type error — nothing in `cargo test --lib` sees it. `.join(` alone has 125 call sites across the `.gg` corpus. R47 Track D1 declined to land it unmeasured.
  - **THE THREE INSTRUMENTS the next attempt must run, none of which D1 ran:**
    1. the ten-row `self_host_runtime` control (`cargo test --test integration --release self_host_runtime`) before and after;
    2. ASan — `cargo test --test security` plus `scripts/sanitize_sweep.sh` on a fixture that stores a `.to_upper()`/`.join()` result;
    3. `--clones=stats` before/after (the `[clone-stats] array_clone=N` line) — flipping a view to owned can also be a CLONE-pressure regression, and this tree measures memory alongside time.
  - **What D1 DID establish**, so the next attempt starts from data: the Rust split above is verified at HEAD; the self-host arm's nine names are exactly as listed after D1 dropped `to_string`/`to_str`/`format`/`concat`/`trim_start`/`trim_end` from it; and D1's emit-C census over 2,188 fixtures showed its own (typing-only, non-ownership) changes produced ZERO changes to emitted C — so the census is a working instrument for this too, and any C-level delta the flip produces is attributable to the flip.
