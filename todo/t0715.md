  - **WHY one more marked root costs 273M string clones:** the prescan is **whole-function conservative by its own design note** (`lower_cow.gg`: *"CONSERVATIVE DIRECTION: whole-fn, not position-aware. A name mutated only BEFORE the bind still suppresses the flip"*). So marking `outer` anywhere kills every borrow-flip on `outer` for the entire function, and a compiler source is full of `x.get(i).unwrap().push(…)`.
  - **THE LEVER, and it is already specified:** Rust gg does NOT collapse this — it keeps the flow-sensitive pair `is_cow_unsafe_at` (dst mutated FORWARD → unsafe to alias) + `is_source_mut_unsafe_at` (source mutated forward → alias dangling after realloc). The self-host collapsed both to one whole-function set. Restoring position-awareness (the machinery is half-present: `cow_mut_max_span` is already position-keyed, and `cow_pristine_after` already consumes it) should recover most of the 273M **without weakening the safety property**, because the flip only needs "not mutated AFTER this bind", not "never mutated".
