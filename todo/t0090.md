- **🆕🧹 [MED — Layering, typed metadata] The `&`/`!`-param auto-deref site reads the WRONG typed bit for "is this an owning param".** `exprs/mod.rs`'s `let is_move_param = ctx.is_owned_local(builder, local_id)` is documented as "`!` params (owned): use Move to transfer ownership", but a `!` param's `ownership` is `Borrowed { Param(self), Unique }` — identical to a `&` param — so `is_owned_local` is FALSE and that branch never fires for the shape its comment names. The single typed bit that distinguishes them is `is_owning_param` (`set_owning_param`'s own doc says so). Measured live: adding a `&`-param-only ownership tag to the else-branch immediately mis-tagged `!` params in the self-host (`Lexer__lex_emit`, `Parser__mk_expr/mk_type/mk_pat`, `parser___decompose_with_stmt`) and produced 10 consume-site violations until `is_owning_param` was excluded explicitly. Switching the predicate to `is_owning_param` is the write-through, but it CHANGES the emitted shape for every `!`-param read (Move + `set_owned` instead of Copy), so it needs its own measurement pass. Grep the other `is_owned_local`-as-a-proxy-for-owning-param sites at the same time.
