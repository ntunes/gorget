- **🆕🚨 [HIGH — the self-host's builtin-vs-user discriminator IS ALWAYS TRUE: every top-level def is registered with the dummy span `(0, 0)`, so `define_replace_or_fail`'s `existing_is_dummy` test cannot tell a prelude placeholder from a definition the author wrote. Found 2026-09-04 by R49 Track F-G while mirroring D46's gate, which needed exactly this distinction and could not get it.]**
  - **MEASURED.** `tests/fixtures/self_host_typechecker/resolve.gg` registers user items as `scopes.define(s.name, DkStruct(), !Span(0, 0))` and `scopes.define(t.name, DkTrait(), !Span(0, 0))` — the SAME dummy span the prelude registrations use for `Vector` / `Option` / the builtin trait names. Instrumenting the D46 gate on a user `struct P` printed `name=P span=0,0`.
  - **⛔ IT IS A LIVE LANE DIVERGENCE, NOT ONLY A DIAGNOSTIC COST — MEASURED.** `define_replace_or_fail` (`tests/fixtures/self_host_typechecker/scope.gg`) allows a redefinition when `existing_is_import and existing_is_dummy`, or when `existing_is_trait and existing_is_dummy and not new_is_trait`. Both guards were written to mean *"the thing being displaced is a PLACEHOLDER, not a real definition"*; with every span dummy, `existing_is_dummy` is UNCONDITIONALLY TRUE and the second guard fires on a definition the author wrote. On
    ```
    trait Shape:
        int area(self)

    struct Shape:
        int side
    ```
    Rust gg reports **`error[E_DuplicateDefinition]: duplicate definition of \`Shape\``**; the self-host driver **accepts the program, rc 0**. The check that was supposed to be conservative refuses nothing.
  - **AND THE DIAGNOSTIC COST.** Rust gg carries the real declaration span (`s.name.span` at `src/semantic/resolve.rs`), so a duplicate-definition or shadowing diagnostic can point at the ORIGINAL. The self-host cannot; this is the same losslessness gap `t0928` records for `Item` spans, one layer up — the parser HAS the name span and the resolver drops it.
  - **FIX SHAPE.** Thread the item's own name span into every `scopes.define` call in `self_host_typechecker/resolve.gg` (and its `self_host_resolver/` twin, a separate blob), leaving `Span(0, 0)` only for the genuinely span-less prelude registrations. Then `existing_is_dummy` means what its name says. ⚠ Verify the two `resolve.gg` copies separately — they are NOT symlinked to each other.
  - **INTENDED:** a user `trait X` followed by a `struct X` is `E_DuplicateDefinition` on the self-host lane, as it is on Rust gg, and `existing_is_dummy` identifies only prelude placeholders.
